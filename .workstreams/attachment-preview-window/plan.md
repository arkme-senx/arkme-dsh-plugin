# 会话附件独立预览窗口（Electron Arkme）

用户已确认独立窗口原型和单窗口复用方案。此前 Flutter 仓定位错误，已停止；本任务仅修改 arkme-dsh-client / arkme-dsh-plugin，基于最新 origin/master 隔离分支，不提交、推送或发布。

原型：系统标题栏，800×600、最小560×400；文件卡片居中，图片/视频填充可用空间；底部多项导航；主聊天无蒙层且始终可操作。

Electron 实现适配：受限的同源 about:blank BrowserWindow，主渲染进程以 React portal 承载已有预览内容，不初始化第二套账号/消息/下载运行时。仅会话入口启用，其他入口保持弹层。主进程限制创建/导航并管理窗口边界；主渲染进程持有唯一预览宿主和附件状态，账号变化时清理。
