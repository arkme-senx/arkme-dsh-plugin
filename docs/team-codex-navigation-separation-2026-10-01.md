# 团队管理与 Codex 对话分工

## 本轮范围

- 对话 → Codex：统一阅读任务、切换任务和成员、查看队列与任务信息。
- 联系人 → 团队：上方显示「团队功能 → Codex 同步」入口，下方始终显示团队成员；不再使用成员/同步管理两个 tab，也不重复呈现项目、任务列表或对话正文。
- 「Codex 同步」在弹窗中管理本机接入和云端授权。支持关闭按钮、Escape、遮罩关闭及焦点恢复；成员列表保持挂载与阅读位置。后续团队功能可在同一区域扩展入口。
- 成员行的「查看对话」携带账号、团队及成员身份进入 Codex 阅读区；「查看团队对话」查看当前团队。
- 从阅读区返回团队时恢复成员页或重新打开同步管理弹窗。阅读缓存按账号、团队、成员隔离。
- 原有任务排除、项目排除和本地记录管理保留在任务的「⋯」中，仅对本人本机任务开放，按任务实际所属团队操作。

## 身份边界

团队目录的 `usr_v1_…` 标识不能直接传给云端 Codex 的数字 `member_ref`。适配层先在当前账号、当前团队的成员目录中校验成员，通过即我号与既有 `/api/v1/team/members/list` 的成员信息映射到数字 ID，不使用昵称匹配。

分页未完成、身份缺失、重复身份、账号切换或无权限时停止查询，不回退展示本人的任务。映射缓存按账号、团队和成员隔离，最多保留 60 秒；最终查询仍由云端检查权限。新增到授权请求白名单的只有既有成员列表只读接口，不含成员移除等操作。

## 验证

- 相关回归：15 个测试文件，175 项通过（包含成员跳转、账号切换、分页身份映射、缓存隔离、管理视图及任务操作边界）。
- `pnpm build` 通过；`git diff --check` 无错误。
- 3100 浏览器：同步管理只显示连接及云端状态；成员行可进入阅读区；本人任务正常加载；同事入口正确选中该成员，当前无匹配任务时不混入本人记录；返回团队恢复成员页。
- 浏览器检查 760px 与 420px 宽度；420px 时入口换到第二行，文档无横向溢出。
- 尚未验证另一位成员产生新云端任务后的跨设备端到端同步；本轮未修改同步协议或进行业务消息派发。
