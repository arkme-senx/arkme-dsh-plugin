# 私聊群互动：正文优先的轻量摘要行

## 已确认的交互

- 保持居中的透明单行提示，不改成普通消息左右头像气泡，不新增预览卡片。
- 最新确认方案使用 20px 发送人头像代替「我／对方」，不再显示完整昵称；头像与正文垂直居中，不增加行高。
- 顺序调整为：发送人小头像 → 正文摘要 → 弱化的群名 → 原群消息已读状态 → 详情箭头。
- 复用现有发送人头像字段及共享图片缓存；缺图、加载中或图片加载失败时显示昵称首字，避免空白灰头像。头像来源变化或图片地址更新后可重新显示新头像。
- 群名最多占行内 24% 且不超过 9em；正文超出时省略，群名也可省略。
- 悬浮或键盘聚焦立即显示完整发送人、群名及已有摘要。提示不会为了补正文再联网。
- 阅读角标使用独立的阅读者说明，不与整行说明重叠；未知状态仍不显示标记。
- 点击或 Enter 打开原快记详情；不改变互动身份、时间顺序、原群已读语义及权限。

## 实现范围

仅修改 `ArkmeInterwovenMentionCard` 摘要呈现及对应中英文文字，详情仍保留原发送人头像和姓名。不新增后端接口。补充覆盖双方头像、缺图、损坏图片、切换发送人、悬浮、键盘、详情点击、长群名、省略和提示清理的测试。

上一轮全量回归唯一失败是公开服务方法清单漏登记两个已实现的方法。本轮补齐明确的 `interwovenReadReceipts`、`sourceMessageExtensionParent`，保留严格全量相等检查，不删除或放宽断言。
