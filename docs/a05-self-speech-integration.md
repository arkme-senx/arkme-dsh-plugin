# A05 本人原音统计接入

音频复用 Audio/ASR 的共享 SenseVoice。保留既有「我的说话统计」面板、词云、列表、详情、试听和定位交互。原音范围与原文定位是不同事实；原文遗漏不会生成伪造转写。

| 能力面 | 接入合同 | 验收证据 |
| --- | --- | --- |
| UI | 原有面板与请求恢复；试听使用源时间和既有播放器；无原文时定位不可用 | 定向交互测试；官方 DSH 安装包实页面词云/列表、原转写漏词试听及旧转写双击播放，真实 loadeddata/playing 事件 |
| Tools | 正式 recordingToolModules 注册；读取不生成；生成走 explicit-user-write 与会话确认/grant | 官方 DSH 真实会话发现、读取、费用确认问题、拒绝非真人消息、真人后续确认后复用同一命令 |
| SDK | 公开能力、查询、创建、出现页及来源类型；当前账号、AbortSignal、dispose | 仓外 consumer 只依赖安装包公开导出，编译并执行；能力版本拒绝、生命周期及同一收据回归 |
| Host owner | RecordingSpeechStatisticsService 统一账号、服务版本、命令及来源语义 | UI/SDK/Tools 共用 owner，跨面读取相同结果；精确授权、账号切换及来源测试 |

协议为 v2。Source.playback 不依赖 ASR 条目；target 只能指向现存真实原文，可空。SDK 生成沿用受信任 DSH 浏览器 Origin 边界；Node 外部插件通过获权的会话 Tool 或插件 UI 发起。SDK 不制造 Origin 请求头。原文的自然日窗口由后端提供，允许真实原文起于统计日之前。

新增录音只影响结果新鲜度，不中断已接收任务。已接收来源的身份/媒体变化或撤权会阻止继续处理和回查；撤权隐藏旧词表。完成后重放 request_id 仍返回原命令，不会再次生成。

跨仓验收使用真实 Audio HTTP/Mongo、原始校验音频及 SenseVoice；外部登录/目录及文本用法 provider 使用确定性 fixture。MySQL 持久计费恢复另行通过现有 Intelligent 测试。三个 AliMeeting 人工转写片段中，5 次“嗯/那个”均通过原音复核；此样本不能代表整体精度/召回，也未证明实际文本供应商的用法分类质量。

验证运行时为未修改的官方 DSH 0.2.1-rc.2，插件基线为用户指定 origin/dev 的 321c94946458723afa21a6f765cd86b99ff5ed01。版本号保持不变；测试使用临时独立 Profile，未替换常驻 DSH。真实页面证据和日志由任务验收产物保存。

插件全量测试已运行：1488 文件通过、26 文件跳过；仅工具目录两处期望值未包含新增能力，修正后该文件 5 测试通过。其余定向合同、typecheck、build 和安装包验收分别记录，不将原先失败的全量调用写成一次全部通过。

本机验收平台为 macOS arm64。更大业务语料、真实文本供应商输出质量和其他目标系统仍需发布验收；不能据本机测试承诺绝对精度或所有平台可用。未提交、推送、合并或部署。
