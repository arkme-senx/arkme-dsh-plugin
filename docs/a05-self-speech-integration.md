# A05 本人原音统计接入

音频复用 Audio/ASR 的共享 SenseVoice。保留既有「我的说话统计」面板、词云、列表、详情、试听和定位交互。原音范围与原文定位是不同事实；原文遗漏不会生成伪造转写。

| 能力面 | 接入合同 | 验收证据 |
| --- | --- | --- |
| UI | 原有面板与请求恢复；试听使用源时间和既有播放器；无原文时定位不可用 | 定向交互测试；官方 DSH 安装包实页面词云/列表、原转写漏词试听及旧转写双击播放，真实 loadeddata/playing 事件 |
| Tools | 正式 recordingToolModules 注册；读取不生成；生成走 explicit-user-write 与会话确认/grant | 官方 DSH 真实会话发现、读取、费用确认问题、拒绝非真人消息、真人后续确认后复用同一命令 |
| SDK | 公开能力、查询、创建、出现页及来源类型；当前账号、AbortSignal、dispose | 仓外 consumer 只依赖安装包公开导出，编译并执行；能力版本拒绝、生命周期及同一收据回归 |
| Host owner | RecordingSpeechStatisticsService 统一账号、服务版本、命令及来源语义 | UI/SDK/Tools 共用 owner，跨面读取相同结果；精确授权、账号切换及来源测试 |

协议为 v2。Source.playback 不依赖 ASR 条目；target 只能指向现存真实原文，可空。SDK 生成沿用受信任 DSH 浏览器 Origin 边界；Node 外部插件通过获权的会话 Tool 或插件 UI 发起。SDK 不制造 Origin 请求头。原文的自然日窗口由后端提供并保留在 target.window，允许真实原文起于统计日之前；定位使用原文条目的时间和既有日期窗口接口，试听仍使用原音词发生时间。

新增录音只影响结果新鲜度，不中断已接收任务。已接收来源的身份/媒体变化或撤权会阻止继续处理和回查；撤权隐藏旧词表。完成后重放 request_id 仍返回原命令，不会再次生成。额度不足会停止自动执行并在原状态行说明原因；在原截止时间内，同输入的新明确重试沿用原任务、检查点和付费身份，不重做已付费批次。输入改变、任务到期或其他类型失败需要新分析。

跨仓验收入口覆盖官方 DSH 安装包 UI/Tool/SDK、真实 Audio HTTP/Mongo、原音 SenseVoice、Intelligent 转发、实际 DeepSeek 和隔离 MySQL 额度账本；外部登录与目录使用隔离 fixture。真实模型的最大 50 条分类批次已验证；单独检验无额度零调用、结算预占归零和已付费结果重放。三个 AliMeeting 人工转写片段及 21 个窗口边界位置用于原音回归；不能外推整体精度或召回率。

验证运行时为未修改的官方 DSH 0.2.1-rc.2。用户指定的 origin/dev 已同步至 9927c3aa56034eda79539d3224729a34ee40f278；3.0.54 来自上游合并，本任务未修改根 README、版本号或 lockfile。测试使用临时独立 Profile，未替换常驻 DSH。真实页面证据和日志由任务验收产物保存。

合并前审核分别记录完整回归、定向合同、typecheck、build、不可变安装包及真实会话证据；失败、跳过和复验不会混写为一次全部通过。资源争用时出现过宽扫描超时，涉及的六个文件 158 项单独复验通过。完整最终结果以同任务 Meta 审查报告为准。

本机验收平台为 macOS arm64。更大业务语料的原音/用法精度与其他目标系统仍需发布验收，不能据有限样本承诺绝对精度或所有平台可用。开发分支为 codex/c20261105-a05-self-speech；本任务不合入目标分支、不部署服务。
