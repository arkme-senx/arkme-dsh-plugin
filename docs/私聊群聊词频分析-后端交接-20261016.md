# 私聊、群聊词频分析：后端交接

> 2026-10-16 交付更新：本文件随本轮插件 dev 同步交付，代码合并状态以 PR 回执为准。下文“未合 dev”等为编写时记录；生产能力与待办以 [后端交接总览](后端需求交接总览-20261016.md) 的本次核验栏为准，拟定接口不代表已经上线。

日期：2026-10-16。当前为前端已实现、待 Chat 后端对接的契约，以下路径不是对现有生产接口的声明。

## 目标和界面

私聊、群聊顶部搜索按钮旁增加「对话分析」入口，其中「词频」页签，右侧面板默认展示**当前对话的全部可查看历史、所有发言者**。默认词云，列表作为详情；点击词语查看命中消息，再定位原消息。

- 私聊：全部 / 我 / 对方（展示当前用户对对方的备注优先名）。
- 群聊：全部人 / 我 / 搜索选择某位历史发言者。已退群但历史消息仍可查看的人也可以选，注明「已离开」。不能仅依赖现成员名单。
- 时间：全部时间 / 按月 / 自定起止日期。自定日期点击「应用」后切换范围。
- 首次需主动「开始分析」；已有结果先展示，后续主动「更新统计」。读取状态不创建计算任务。
- 无能力支持时显示「对话词频服务尚未接通」，禁用开始分析，不用当前加载的几页消息冒充全历史，也不显示模拟词云。

## 后续扩展（2026-10-16）

统一入口新增「活跃时间」页签，详见同目录《私聊群聊活跃时间分布-后端交接-20261016.md》。两个页签共用日期、人员筛选；participants 的人物ref必须跨两项分析兼容，绑定同一账号和会话。两项能力独立上线，不互相依赖。

## 统计口径（必须统一）

1. 以当前登录用户有权限查看的、该私聊或群聊的原生消息为输入。个人快记、关联录音卡片的完整转写、跨群穿插消息、通话自动摘要，不因出现在同一屏就混入聊天词频。后续扩展可另加来源维度。
2. 全部人的含义是全部消息作者；选择某人必须用服务端稳定身份筛选，不按昵称匹配。机器人消息若属于授权可见聊天消息，应明确作者，保持所有人总量可解释。
3. 只统计消息作者的正文。回复引用、转发的他人原文、卡片引文、附件名、系统通知、表态、链接预览、图片 OCR 不冒充作者发言。若引用原消息本身在此会话范围内，按原消息计一次。
4. 语音消息已有转写可以纳入，但标记 `voice_transcript`，不能宣称经过原音核验。这与「每日本人说话词频」的原音核验服务是两个范围；后续如果提供原音纠正应带版本并重新统计。
5. 富文本解析出可分析纯文本；去 HTML/Markdown 标记，不重复合并富文本正文与兼容纯文本副本。中文分词、停用词、大小写、Unicode 规范化及词典版本都由后端统一。明确分词规则，不能用大模型猜次数。
6. `count` 为词语出现次数，`messageCount` 为包含该词的去重消息数。例：一条消息含「工作」3次、另一条1次，则 count=4，messageCount=2。
7. 编辑、撤回、对当前用户删除、权限变化、语音转写补齐，应更新索引/使结果过期。旧快照不能泄露已不可查看消息；消息详情和定位每次重验权限。
8. 日期按请求时区计算自然日，起止日期均包含。内部查询建议 `[from_date 00:00, to_date+1 00:00)`。全部时间时两个日期都为 null。
9. 结果必须覆盖全部授权范围；若分批计算，明确 analyzed/eligible 进度，不能静默截断到最近 N 条。词云前端仅展示前40词，列表展示服务端返回的词表（最多5000）；若将来需要更大词表，增加分页版本，不静默丢失却标称全部。

## Chat 后端 API 草案 v1

全部 POST，经现有 Chat 鉴权入口；不走 Audio 接口。前端本机参数包含 `accountScope` 和签名 `sourceRef`，插件验证当前账号并解析后，仅向 Chat 后端发送会话 ID 和下面的范围。后端必须再次校验会话访问权限，不信任客户端 ID。

### 通用范围与响应回显

除 capabilities 外，全部请求与响应必须包含同样字段：

```json
{
  "schema_version": 1,
  "scope": "conversation_words",
  "chat_session_uid": "example-session",
  "time_zone": "Asia/Shanghai",
  "from_date": null,
  "to_date": null,
  "sender": "all"
}
```

`sender` 为 `all` / `self` / `peer`（仅私聊）或 participants 返回的不透明稳定 `ref`。具体人不能用名字当 ref，ref 需绑定账号及会话。所有响应严格回显范围，不匹配会被插件拒绝；完整快照键包含账号、会话、时区、日期、发言者及统计算法/数据版本。

以下示例省略通用回显字段，生产必须合并这些字段。统一响应外壳沿用 `authenticatedChatPost` 已有解包约定。

### 1. `/api/v1/chats/word-frequency/capabilities`

请求 `{ "schema_version": 1, "scope": "conversation_words" }`。

```json
{
  "schema_version": 1,
  "scope": "conversation_words",
  "supported": true,
  "full_history": true,
  "historical_senders": true,
  "sender_filter": true,
  "source_navigation": true,
  "idempotent_create": true
}
```

尚未实现时返回 404/501 或 `supported:false`。鉴权、超时、5xx 不应伪装为不支持；前端会显示真实错误。只有完整协议可用后再置 true。

### 2. `/api/v1/chats/word-frequency/state`

请求通用范围。只读，不能隐式提交计算。无结果时 result/job 均为 null。示意结果：

```json
{
  "stale": false,
  "job": null,
  "result": {
    "id": "immutable-result-id",
    "corpus": "authorized_conversation_messages",
    "quote_policy": "authored_body_only",
    "updatedAt": 1792108800000,
    "fromAt": 1792108800000,
    "toAt": 1792112400000,
    "analyzedMessages": 800,
    "eligibleMessages": 1000,
    "excludedMessages": 20,
    "voiceTranscriptMessages": 12,
    "words": [
      {"key": "stable-word-key", "text": "工作", "count": 120, "messageCount": 65}
    ]
  }
}
```

- 时间为毫秒；fromAt/toAt 为结果覆盖的真实消息时间，空语料时都为 null。
- eligibleMessages 是当前筛选内可分析消息总数；analyzedMessages 是已计入此快照的数量。excludedMessages 是范围内无可分析正文而排除的数量，不是权限外消息数。
- voiceTranscriptMessages 是 analyzedMessages 中使用语音转写的消息数。
- 所有计数必须是非负整数，不能 null、NaN 或省略后由前端当0。词条 count/messageCount >0。
- 每次数据或词典变化的新结果须有新 id；旧结果可与进行中的新 job 同时返回，并标 stale。不能修改同一个 id 指向的数据，避免详情分页漂移。
- job 为 null 或 `{ "id":"job-id", "status":"queued|processing|failed", "completed":100, "total":1000 }`。单位为待处理消息，completed≤total。失败应保留旧结果但允许重试。

### 3. `/api/v1/chats/word-frequency/create`

通用范围 + `request_id`（UUID）。响应通用范围 + 相同 request_id + state 形状，必须存在 job 或 result。

后端对 `(account, request_id)` 幂等；同 ID 不同范围拒绝409；同范围同 ID 重试返回同任务/结果。前端把未确认请求保存在 sessionStorage，超时后「核对提交」复用同 ID。服务不能重复排队、重复计费。失败新一轮重试可生成新 ID，但已确认任务的恢复仍应服务端处理。

前端仅打开面板时读 state，已有任务每5秒轮询一次，后台隐藏时暂停；网络错误停止自动重试，用户主动检查。

### 4. `/api/v1/chats/word-frequency/participants`

通用范围（sender固定all）+ `{ "search":"", "cursor":null, "limit":50 }`。

```json
{
  "search": "",
  "items": [
    { "ref":"opaque-person-ref", "name":"备注优先的名字", "isSelf":false, "former":true }
  ],
  "next_cursor": null
}
```

从该范围内授权可见消息的**历史作者**取唯一人物，不能只查 active 群成员。搜索当前查看者的备注、昵称；不要把 A 用户的私有备注返回给 B。保留已离开、已注销但历史消息仍可见的作者，无法识别的姓名可返回「已注销用户」等显示名，身份 ref 仍须稳定且彼此不同。ref 不得使用保留字 all/self/peer。

分页稳定、无重复、cursor不循环；搜索与范围更改必须使用新游标。响应 search 为请求去首尾空格后的原字符串。

### 5. `/api/v1/chats/word-frequency/messages`

通用范围 + `{ "result_id":"...", "word_key":"...", "cursor":null, "limit":50 }`。

```json
{
  "result_id": "immutable-result-id",
  "word_key": "stable-word-key",
  "items": [
    {
      "key":"message-key",
      "sourceRef":"opaque-source-ref",
      "senderName":"周鹏",
      "text":"可查看的作者正文",
      "sentAt":1792108800000,
      "count":2,
      "basis":"text"
    }
  ],
  "total":65,
  "next_cursor":null
}
```

basis 为 text 或 voice_transcript。按真实发送时间及稳定消息ID分页，**一条消息一行**，count 为该词在该消息中的次数。total 为当前仍可查看的去重命中消息数。已失权/删除消息不能返回残留正文；允许快照计数与实时可查看total不同，置结果stale，提示更新。原消息存在但无法定位时 sourceRef可为null；不能编造另一条消息顶替。

### 6. `/api/v1/chats/word-frequency/source`

通用范围 + `{ "result_id":"...", "source_ref":"..." }`。

```json
{
  "result_id":"immutable-result-id",
  "source_ref":"opaque-source-ref",
  "available":true,
  "message_uid":"actual-message-uid",
  "send_at":1792108800000
}
```

必须校验 source_ref 与当前账号、会话、结果、日期、发言者、原消息关系，不能跨会话定位。前端只会打开当前会话并用真实 message_uid/send_at 精确定位，不会全文模糊搜索另一条内容。不可查看时 available:false 或明确404/409，禁止返回消息正文。

## 建议实现顺序

1. 基于 Chat 消息存储/检索索引构建 per-message 分词及计数，复用现有消息访问策略。与旧快记关键词接口分开：它不能提供会话内完整消息与按作者筛选。
2. 首次全历史后台任务，按批次推进cursor与进度；按 message UID + 内容版本 + 词典版本幂等建索引，避免一次把全部历史塞进大模型。
3. 会话/作者/日期维度聚合，利用同一索引组合筛选；新的消息版本增量更新，撤回删除扣减、失权重验。
4. 发布 capabilities 之前打通 state/create/participants/messages/source；前端可直接对接 v1。若 API 路径或字段另有约定，请在发布前同步修改插件适配和测试。

## 验收清单

- 私聊双方各含相同词、多次重复词；全部=双方合计，单人不串数据。
- 大群全部时间包含已离开成员可见历史；同名成员按身份区分；成员搜索分页正常。
- 早期历史超出当前客户端页仍被统计；月份、时区边界及自定日期正确。
- 正文含3次同词：出现3次/涉及1条；引用他人原文不重复归到回复者。
- 语音转写明确标注依据；文件名、系统通知、不可查看正文不混入。
- 生成中切换会话/人/时间或账号，旧响应不能覆盖新筛选；关闭面板取消本机等待，不假定远端任务已取消。
- 超时重试同request_id仅一个任务；刷新/重新进入可读同结果。
- 编辑、撤回、删除、退群权限变化可正确失效；定位前二次鉴权；拒绝伪造会话/人/来源。
- 生产尚无接口时显示未接通；网络失败单独显示；不能显示伪造词频或静默小范围统计。
