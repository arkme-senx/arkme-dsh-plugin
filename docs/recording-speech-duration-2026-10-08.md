# 录音日历：转写输入时长前端接入准备

日期：2026-10-08。范围：插件前端、数据投影和后端交接文档。

## 功能

在每日「人声存储 / 转写字数」统计行追加「转写输入时长」，保持原有灰色文字、自动换行，按小时、分、秒展示。

统计目标是归属于当前用户的录音送入系统语音转写模型的音频量，用于了解转写工作量。它与净发言时长、完整录音范围、GPU 运行时间及用户套餐扣费时长分别定义。

- 复用现有日录音请求，不增加远程请求。
- 前端已按建议的 `child_ls[].asr_input_metrics` 合同准备解析；后端确认正式字段后再完成适配与真实数据联调。
- 分别累计后端返回的输入窗口，支持跨日截取、重复 child 去重和账号归属过滤；不合并真实重复输入的重叠窗口。
- 区分实测、历史估算、部分统计、处理中和不可用；估算显示「约…（含估算）」。
- 旧接口缺字段时显示「暂不可用」，不会用原始音频时长、文字边界或文件大小生成假值；真正空日期可显示 0。

## 后端交接与发布边界

[后端交接文档](recording-asr-input-backend-handoff-2026-10-08.md) 列出了字段、统计口径、可协商的响应合同、同事交付内容和联调验收条件。

本次提交不包含音频后端、ASR worker、计费或退出登录修改。后端同事负责确认数据来源、实现、测试与部署，再由前端对接。此前本地试写的后端代码仅为未采用的参考，不是已部署能力。

前端可以先合入分支；但“前端已合并”不表示真实时长已经可用，也不表示后端已验收。在配套接口交付前，有录音的日期可能持续显示「转写输入时长 暂不可用」。

## 验证

- 7 个相关前端测试文件共 189 项通过，覆盖缺字段降级、输入窗口重叠与重复、账号归属、跨午夜、历史估算、空日期和已有录音页面交互。
- TypeScript 类型检查、类型声明构建、bundle、Windows 凭据工具及可执行入口验证通过。
- 390px / 1100px 的实际 React 组件预览通过，中英文无横向溢出。
- 独立 Web 环境已复用现有客户端登录态读取真实录音，确认旧接口下新增统计显示「暂不可用」。未修改已安装客户端文件。
- 真实时长的端到端验收仍待后端正式交付。
