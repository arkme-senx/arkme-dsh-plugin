# 群成员 Bot 名单与操作回归

## 本轮范围

- 群成员侧栏保留原有人类成员列表，在下方显示本群已安装的全部受支持 Bot（Webhook / OpenClaw），不限于当前用户创建的 Bot。
- 名单来自 `group.bots`，按 `installed` 过滤并按稳定身份去重；不从个人 Bot 目录推断群成员关系。
- Bot 行复用普通群成员的尺寸与排布，显示 BOT 标识；标题区分别展示人数与 Bot 数量。
- 鼠标悬浮、右键与键盘下箭头可打开统一菜单；点击行打开 Bot 资料。
- 群主可进入移除确认。仅在服务确认移除成功后更新当前群名单并重新核对；移除失败不隐藏成员。
- 切换账号或群聊不展示旧范围数据；过期响应被取消。读取失败保留已知名单并提供重试，不伪装成空列表。

## 验证

- 类型检查、构建、差异空白检查通过。
- 相关回归 8 个测试文件、438 项通过。其中新增名单回归覆盖 7 项：两种 Bot、去重、安装状态、延迟响应隔离、变更后刷新、错误重试、行交互及人数显示。
- 独立 Web 3100 实页：测试群显示 5 人、5 Bot；包含通知型 Bot 和 OpenClaw Bot。点击通知型 Bot 可打开资料；菜单出现红色「移出群聊」，确认弹窗提示历史消息保留。
- 实页移除确认已取消，没有执行真实移除；成功移除后名单更新使用自动化模拟验证。
- 鼠标进入触发与左侧定位参数通过组件测试验证；浏览器验证了右键菜单和点击入口。

## 边界

- 本次只更新 3100 独立预览，未修改已安装桌面客户端，未提交或推送。
- Bot 快记查询沿用现有实现；未取得完整统计时不显示虚假的 0 条。Webhook 不支持的 @ 对话入口保持禁用。
- 页面启动时观察到独立通话模块的 TRTC 音量工作线程预加载错误，不属于本轮 Bot 名单改动，也未在本轮更改通话逻辑。
