## 此次不需要新接口的部分

- 长文默认编辑、停止输入 5 秒自动发布、连续输入最多 30 秒提交一次、关闭或切换时兜底提交，沿用现有创建和带版本的更新接口。编辑中不显示时长；发布不重建编辑器。
- 正常离开会等待当前改动提交；失败保留本机草稿，重开按原版本恢复，版本冲突不能覆盖其他设备的新内容。本机草稿不是跨设备草稿同步。
- 会话内新建待发送长文仍需用户确认发送，不会因输入而自动发给其他人。
- 第二栏「＋ → 添加长文」直接复用长文编辑器，固定使用当前账号的发给自己目标；不会继承当前私聊或群聊目标。
- 长文左侧目录、右侧多级大纲、选中文字 Markdown 格式浮栏，均为插件 UI；格式仅使用当前 Markdown 可保存的能力。
- 长文更多菜单的编辑记录、复制链接、转发、软删除和记忆快照，复用现有消息操作及权限接口；Markdown 和手机阅读图片在本机导出。
- 地图暗色适配、筛选按钮布局、缩放位置保持与按现有位置数据聚合，均由本轮插件完成。已有位置数量及覆盖范围不当作所有历史的精确总数。
- DSH 卡片空闲且全部已读时显示最近更新的真实对话标题，沿用原生会话状态事件，不增加后台轮询，不改云端协议。

## 语音输入与自动发布的组合语义

语音识别本身只返回文字，不创建消息或录音记录。对话输入框仍由用户发送；长文中的文字属于当前编辑内容，结束听写后沿用长文自动发布流程。听写进行中不提交不完整的识别内容。不能把“识别不直接创建消息”理解为长文结束听写后永远不会自动发布。

## 后端交付与联调要求

- 请回传正式路由、字段、错误码、部署环境与版本、脱敏真实请求和响应。
- 共享分类须明确返回实际生效的分类；旧接口忽略参数并返回所有长文不算接通。
- 语音接口区分权益不足、文件不存在、启动失败、等待和完成；重试的入队及计量语义需明确。
- 共同内容聚合按实际发送事件及原会话权限返回数据，不能把同一段正文当作去重身份；分页游标须绑定账号、目标人、范围及权限。
- 当前已可用的插件功能继续沿用；新接口提供后替换服务适配层并做真实联调，不重新设计入口。
