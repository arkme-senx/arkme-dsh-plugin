## 最终入口规则

- 完整策略：存在当日可读的独立结果（含失败任务保留的部分正文），或正在生成的任务，或完整原件仍在服务端保留期内、正式处理成功、对象实际存在且字节长度吻合，才提供入口。已接纳但失败且无正文的任务没有既有重新处理命令，不伪造“可以生成”。
- 豆包：已保存的当日增强正文不依赖原件。新处理沿用既有增强规则，允许已确认输入、历史保留输入或完整可用的系统播放切片/播放包；不能直接复用完整策略的 48 小时条件。缺失输入与权限/存储故障严格区分。
- 两项按各自可用性独立显示；可能有两项、一项或没有。查询中显示检查状态；查询失败提供重试，不宣称无结果，也不打开空对比页。
- 可用性查询仅读取一页源件及其时间、媒体和任务/结果元数据，不下载/解密转写文字，不读取声纹向量，不登记任务、采用旧媒体或发送模型请求。Mongo 使用既有集合和索引，没有新增缓存事实或数据迁移。
- 日期范围按源件、内部处理分片和对比偏移核验；跨日结果只属于相交日期。单文件菜单使用整个文件范围，不受当前日历日裁剪。切日、切账号、页面停用会取消旧请求；新上传/正文版本变化、窗口恢复焦点和原件到期会重查。
- 旧客户端不请求 `include_availability` 时，Sources 响应保持原样；新字段和读取参数是可选扩展。Host、SDK 和已有 `arkme_recording_strategies` 的 sources action 共用同一权限与读取 owner，不返回对象路径、凭据或内部定位信息。

## 兼容与恢复审查

新录音统一默认值只在接纳候选上设置，先用原始请求参数计算已有幂等身份，再固定当前算法。已接受任务重放返回首次持久化的 Session。旧上传参数、旧偏好接口、已登记的原生上传和持久队列仍兼容；新 UI/共享导入链不再读取偏好、补齐或传递默认策略。模型配方 ID、空历史值的既有执行语义、结果加密、原始说话人身份和独立对比结果集合不变。
