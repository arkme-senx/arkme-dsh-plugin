# 录音与通话转写标记、更正：后端交接

日期：2026-10-21。当前仅实现插件前端与本机 Host 存储，尚无云端同步协议；本文接口为建议，不代表已上线。

## 当前已实现

- 录音每日转写和通话详情共用文字选区组件：复制、全选、标记、查找、替换。全选针对当前文字块，查找分别限定当天转写与当前通话。
- 右键文字块提供复制、多选、播放；多选按时间复制、播放。原有录音转发仍要求同一次录音、同一转写来源。
- 标记使用选区全文摘要、前后文、位置共同定位；替换只改所选的一处，支持恢复原文。
- 标记、更正保存于插件稳定账号目录 SQLite `local_transcript_edits`，按环境、账号、来源范围和片段 ID 隔离，不依赖网页端口。客户端重启后可读取。
- Host 内部接口 `transcript.local.read/change` 校验当前登录账号，并使用 revision 比较更新，拒绝过期覆盖。它们是本地接口，不应复制为生产网关的免鉴权接口。
- 原始 ASR 文本、声纹归属、音频、云端日总结与时间轴均未修改。显示“本机更正”，标记菜单注明本机保存，不声称跨设备同步。

## 后端需要补齐的协议

### 1. 稳定身份与权限

录音和通话分别返回长期稳定的来源 ID、片段 ID、转写版本与文本摘要；不能把临时签名 URL、页面索引、签名 itemRef 当作持久身份。分段重新生成后需提供旧片段到新片段的映射，无法可靠对应的更正和标记应返回失效状态。

读写均从登录身份验证来源访问权。个人录音先仅本人可编辑；通话中的他人发言允许个人更正视图，不自动改变对方看到的原文。若产品后续需要共享更正，另明确编辑权限与参与方可见性，不能默认广播。

### 2. 查询与更新（建议能力，不限定 URL）

- capabilities：支持来源、可编辑范围、标记长度、云端同步能力。
- 批量读取：source kind/id、segment ids → original text/version/digest、corrected text、correction revision、marks、访问状态。
- 选区更正：operation_id、segment id、expected_revision、original_digest、UTF-16 选区 start/end、选区文字与前后文、replacement。
- 取消更正/恢复原文：expected_revision、operation_id；作为新版本保留审计历史，不能物理删掉同步记录。
- 新增/取消标记：operation_id、annotation_id、锚点、expected_revision；取消保留同步墓碑。
- 同步增量：cursor/revision + 变更和墓碑，重复提交幂等；冲突明确返回当前版本，禁止静默最后写入覆盖。

选区可参考插件现有 `ArkmeMessageQuote` 的 `arkme-text-v1` 投影、SHA-256 digest、UTF-16 索引及前后文。服务端必须独立校验，不能信任客户端提交的任意全文或来源 ID。

### 3. 原文变化与音频定位

保留原始 ASR 版本与人工更正版本；每次更正记录操作者、时间、前后内容和来源。改字不改变音频起止时间；词级对齐有失效风险，应标记需重对齐。旧摘要不应悄悄变成新摘要；需要重新生成时明确使用哪个转写版本，并保留旧版本。

后端原文更新后，只有锚点唯一且证据一致才可迁移标记。近似匹配有歧义时显示待复核，不能把同名词的另一处当作原位置。目前前端已在原文变化时停止应用旧更正，并允许恢复当前原文后重做。

### 4. 本机数据迁移

正式协议具备稳定 ID、权限与版本冲突能力后，再由用户确认将本机更正上传。迁移携带 operation_id 并逐条确认，不能清空未确认数据。禁止把本机存储直接当作所有通话参与方的共享事实。

## 验收要点

1. 同一句出现多次相同词，只更正选中的那一次；中文、emoji、换行位置正确。
2. 原文变动、两端同时编辑、请求结果不明时不覆盖新版本；重试不重复创建。
3. 重启、换设备、切账号、生产/测试环境隔离；取消标记和恢复原文不会被旧同步复活。
4. 无访问权限、来源删除、音频不存在、网络失败分别返回明确状态。
5. 更正后仍可播放原音频；标记错位不能静默；录音、通话、普通聊天使用一致的选区交互。
6. 后台刷新不得清空当前转写、滚动位置或用户选区。

## 前端代码入口

- `src/client/TranscriptInteractions.tsx`：录音/通话共用交互，后续可替换读写 transport。
- `src/local-transcript-state.ts`：本机版本比较、原文与标记校验。
- `src/local-database.ts`：稳定账号存储。
- `src/client/ArkmeRecordingSurface.tsx`、`src/client/ArkmeCallDetailContent.tsx`：页面接入。
