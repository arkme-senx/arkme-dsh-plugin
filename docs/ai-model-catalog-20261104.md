# AI额度区域的官方可用模型目录

> 后续已按用户确认迁移到统一「即我设置 → 模型」。当前行为与验收见 [统一模型设置入口](model-settings-migration-20261104.md)。下文保留 `1ad881ec` 初版独立目录弹窗的实现和验收记录。

在已确认交互方案后实现于 `codex/ts1104-11-AI额度消费统计`，沿用当前AI额度工作区；此前消费统计及其后端改动独立保留。

## 用户行为

- 设置 → 用量与额度 → AI额度下方新增「可用模型」，与消费记录并列；额度详情弹窗复用同一组件，亦具有该入口。
- 打开独立原生模态弹窗，默认全部官方模型。支持名称/提供方搜索，以及DSH对话、Arko对话、录音、识别与分析筛选。
- 显示官方名称、提供方、已确认能力和适用场景；展开按场景列出计费方式、已有价格。此处用于查看，选用仍在对应功能的模型选择器完成。
- 已公开的托管报价按每1,000 Token展示输入、缓存输入、输出的精确字符串积分，不使用余额显示函数的两位截断。其他场景保留其目录提供的计费说明，未知计费明确标注，不把DSH价格套到录音/分析场景。
- 只有精确官方路由标识一致才合并跨场景条目。同名不同路由或提供方继续分别展示，未声明的图片/推理能力不从模型名称推断。
- 标题、搜索、筛选及底部信息固定，模型列表内部滚动；窄窗口自然换行。Esc只关闭当前弹窗，关闭恢复入口焦点。读取失败、部分来源失败、无搜索结果有独立状态；提供刷新/重试。

## 数据与兼容

复用 `models.directory`，新增可选 `officialOnly:true`，经Host、ArkmeService、ModelDirectoryService共同处理。SDK保留原有 `(scope,signal)` 用法，第三个可选参数 `{officialOnly:true}` 获取官方目录。默认调用、用户自提供模型目录、现有模型选择/生成行为保持不变。

官方模式直接读现有已发布用户目录 `/api/v1/managed-ai/models/query`，无需DSH远程连接或用户自提供渠道；结合现有Arko、录音、探索模型目录。新解析器限制最大256条托管模型，校验稳定标识、提供方、能力/推理声明与精确非负积分报价，只投影明确公开字段，不透出密钥或内部配置。目录读取前后及最终返回前检查账号作用域；关闭/刷新/换号取消请求，界面也丢弃迟到响应。不新增生产后端接口、数据库迁移、模型激活或付费生成请求。

- 固定端口3177、官方DSH 0.2.1-rc.2、独立DSH_HOME/状态/Keychain，复用用户授权的桌面真实登录态。模型目录读取生产的现有只读接口；此前消费统计仍连隔离MySQL的真实账单快照。
