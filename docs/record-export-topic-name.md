# 导出主题名接入

Record 导出分页返回可选的 `topic_core`，插件在每条记录的时间和正文之间写入 `主题：名称`。空标题显示“未命名主题”，缺失摘要或有效主题 UID 时保持旧版输出。主题名称按纯文本转义 Markdown / HTML 并折叠空白；不从本地缓存猜测归属，也不逐条请求主题详情。Record 继续持有主题归属与隐私过滤。

## 性能与兼容

只在已有 100 条/页循环内按名称长度进行字符串处理，不新增远端调用、缓存、订阅或并发。保留 100,000 条、1 GiB 内容、30 分钟、单实例互斥与流式磁盘背压边界，主题行计入既有字节限制。用分页请求计数覆盖无 N+1；不将功能测试声称为性能提升。

后端依赖 Record 导出可选字段（Record MR !473）；旧后端不返回字段时仍可正常导出。发布时先部署后端，再更新插件。回退插件不影响后端或数据；没有数据库写入语义变化。

本次不修改根 README、插件版本或依赖锁文件，不发布 npm / Release Set，也不替换常驻 DSH。
