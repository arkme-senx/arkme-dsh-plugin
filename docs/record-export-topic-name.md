# 导出主题名接入

Record 导出分页返回可选的 `topic_core`，插件在每条记录的时间和正文之间写入 `主题：名称`。空标题显示“未命名主题”，缺失摘要或有效主题 UID 时保持旧版输出。主题名称按纯文本转义 Markdown / HTML 并折叠空白；不从本地缓存猜测归属，也不逐条请求主题详情。Record 继续持有主题归属与隐私过滤。

## 场景与 owner（2026-11-05）

| 场景 | 主题来源和输出 |
| --- | --- |
| 旧完整 ZIP（Tools / SDK） | Record `records/page.topic_core`，时间后、正文前输出主题行。 |
| 范围 ZIP：全部 / 按日期 / 增量 | Record `range/page.topic_core`；同一 ZIP owner 和格式化函数。 |
| 文件夹：全部 / 按日期 / 增量 | `BackupDirectoryStore.writeReadable` 使用已验证的分页摘要，保留附件复用、保存回执和取消语义。 |
| 已保存文件夹重导出 / 离线导出 | 从本地完整副本读取相同摘要；离线显示原有“数据截至”提示，不能声称是在线最新名称。 |
| 会话 Markdown：全部 / 未分类 / 主题子树 / 私聊 / 群聊 | 仅使用每条记录已授权的 `selfTopic`，时间后输出主主题名；目录树仅用于范围标题，不覆盖记录名称。私聊/群聊没有此摘要时不补查私人归属。 |
| 长文 Markdown / 分页图片 | 使用当前详情的 `actionItem.selfTopic`；自有个人长文复用轻量主题 metadata 验证个人主题与公开状态，接收的聊天快照不查询作者私人主题。图片使用原始单行文本，Markdown 安全转义。 |
| Arko / Team 会话历史 | 独立会话 owner，不含个人主主题合同；保持原输出，不能把会话名当作个人主题。 |
| 连续录音转写 TXT、原文件下载、截图、群邀请图片 | 不是个人快记导出，不推断或附加主题归属。 |

`record-export-topic.ts` 只持有标题折叠、空名和转义规则。Host 中 ZIP / 文件夹继续各自执行已有传输和保存流程，UI 继续使用已有 Host / SDK / Tools 合同；没有新增业务入口或桌面桥。

## 性能、隐私与兼容

- 插件的批量导出不新增远端请求，只处理现有分页摘要；主题行计入原有制品大小及摘要。长文单条详情增加一次既有轻量 metadata 校验，不遍历主题或正文列表。
- 范围后端需要同一任务的配套改动：准备阶段批量解析主题并纳入内容 digest，保存账本仅增加 `topic_digest`，不保存主题名或正文；升级前账本缺省兼容。
- 主题改名、移动、删除和隐私变化不一定写正文变更日志。增量按现有账号/设备/附件策略索引扫描账本的 UID / 主题摘要，每页 100 条、最多 100,000 条；每批最多一次关系和一次去重主题查询，仅为发生变化的记录读取正文，不重复读取同批主题事实。
- 读取冻结分页或签名附件前复核主题摘要；变化时要求刷新，避免导出已变为私密的旧名称。查询失败或冲突主归属不能当作无主题。
- 旧后端缺少摘要时兼容省略，不猜测。上线顺序为后端全部节点升级，再更新插件；已生成且主题变化的旧任务需刷新。回滚保留现有账本和本地备份。
- 不修改根 README、插件版本或锁文件，不发布 npm / Release Set、不替换常驻客户端。单机隔离测试不能代替测试服负载、真实账号、桌面原生选择器或 Windows/Linux 验收。
