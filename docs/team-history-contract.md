# 团队历史能力

本能力只处理当前 Team 对话；复用原日历、搜索、人物列表、分析及导出入口，调用正式 Team history 合同。普通 Chat、个人 Record 与实时 timeline 保持独立。

| 消费面 | 必做范围 | 验收状态 |
| --- | --- | --- |
| Host owner | 账号前后检查、会话/人物/result 不透明引用、范围/版本错误、授权分块下载 | Host 边界与账号/引用测试通过 |
| UI | 服务端分页、日期/按人、词云/活跃桶来源、定位、进度/取消/失败/下载 | 服务端查询/来源/定位的组件交互测试通过；实际跨服务页面验收仍待完成 |
| Tools | 通过正式注册/grant 查询和创建私有导出，返回安全结果与下载描述，不回传二进制正文 | 官方 DSH 0.2.1-rc.2 中，tgz 隔离安装、真实会话发现并调用全部 12 个操作通过（合成业务适配器） |
| SDK | 公开类型、能力探测、同义调用、可继续的导出块读取与生命周期取消 | tgz 仓外 consumer 编译与执行通过；能力不支持、AbortSignal 取消和分块继续读取通过 |

搜索命中是有界预览，不能将它直接当完整正文用于编辑、引用或媒体授权；点击沿既有 locate 读取当前消息。backend cursor 不复用 beforeSeq。

导出先等待服务端完整文件证据，再以当前账号逐块读取。Host 检查块 hash、递增 offset、总字节与最终 SHA-256；本地下载路由沿既有 loopback/origin 边界，失败中断传输。导出文件不包含服务生成的媒体签名地址或内部定位凭据。

所有新能力只落本任务插件 worktree，不改 DSH、根 README、版本号及 lockfile。用户指定 dev 为基线，覆盖 skill 的 master 默认值。

验证：类型检查、构建通过；全量 1,286 个测试文件通过，18 个按既有条件跳过；14,483 条测试通过，24 条跳过。实际 Team → Record 数据闭环、移动端以及最终合并审查仍另行验收，不将合成适配器结果当后端业务正确性证据。
