# Arko 回复后端发布审核记录

## 已确认并修复

- Record、Chat 合法快照经转义超过旧 256 KiB 响应上限：改为 1 MiB wire 上限，正文与 display 各自仍限 128 KiB。
- 个人及主题 Arko 回复误用局部纯文本引用校验：独立按当前归属、状态和隐私锁授权；RPC 返回后重查版本与权限；回执隐藏不可读快照。
- GetQuotedEdgeReceipt 漏判 ThoughtReply，导致实际保存后误报 50001：补齐类型判断，保留账号、摘要和移除状态约束。
- 历史默认内部读取过滤保留 asen bot 提及，而消息证据投影也未读取提及：Chat 触发判定使用消息证据，Record 仅为该投影补读现有字段，默认过滤保持。该修复经失败的跨服务用例先复现，再连续三轮通过。
- 创建锚点编号 6 已被 develop 使用：本轮 Chat Arko 创建锚点固定 7，补协议回归。
