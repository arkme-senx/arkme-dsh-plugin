# 桌面私聊快捷建群

在真人私聊右上角点击「发起群聊」，自动带入自己与当前聊天对象，再选择至少一位联系人即可创建新群。成员选择来源复用联系人与最近私聊的统一目录，支持备注、昵称和账号搜索。当前聊天双方固定保留，其他人可以移除。群名称可选，默认公开，最多 100 人。

选人后自动检查自己仍在其中、且包含全部所选成员的已有群：

- 成员集合完全一致：显示「成员完全相同」与人数。
- 包含全部所选成员及其他人：单独显示「另有 N 人」。
- 可以直接打开已有群，也可以明确选择「仍然新建群聊」。
- 只有完整检查成功且没有匹配群时，才显示未找到。检查失败或超过扫描上限时显示检查不完整，支持重试或明确选择继续创建。

提交前再检查一次。此时才发现的匹配群会返回给弹窗，等待用户选择，不自动建群。建群直接在一次原生请求中包含当前聊天对象与全部新增成员；不会先建空群再逐个加人，也不会迁移或分享旧私聊历史。

## 复用边界

本次仅修改 `arkme-dsh-plugin` 的界面及桌面 Host 编排。云端 `jotmo-chat` 等后端仓库无修改，无新增云端接口、数据表或部署。

| 已有能力 | 本次用途 |
| --- | --- |
| 联系人 / 最近私聊统一目录 | 分页选择已注册的真人；复用备注、昵称、头像与账号绑定的联系人引用 |
| `/api/v1/chats/detail` | 校验当前账号仍处于该真人私聊，并读取真实聊天对象 |
| `/api/v1/chats/common-group/query` | 翻页读取与当前对象的共同群，再以已有群 UID 分批查询其余所选成员并求交集 |
| `/api/v1/chats/members/page` | 对人数相同的候选群核验完整有效成员集合，避免误标为完全相同 |
| `/api/v1/chats/create-group` | 复用 `member_user_ids` 一次性建群，创建者由原生接口自动加入；复用公开状态与请求 UID |
| 现有来源激活逻辑 | 打开已有群或刚创建的群 |
| 现有手机号绑定拦截 | 只拦截创建写入；选人、检查、打开已有群继续可用 |

重复检查是实时读取后的提示，不是云端唯一性约束；查询与创建之间可能有其他设备或其他人创建新群。因此保留明确另建入口，未声称能阻止所有并发重复群。共同群扫描最多 100 页；联系人选择最多读取 40 页，超过上限均明确显示不完整。

## 账号与重试

- UI 只提交当前账号签发的不透明联系人引用；Host 重新解析身份，忽略调用者自填的用户 ID。
- 所有链路核对账号与环境。关闭弹窗、切换账号或切换会话时取消旧请求，丢弃过期响应。
- 防止重复点击提交。创建结果待确认时锁定成员与设置，重试沿用同一个原生请求 UID 和参数；已确认创建但打开失败时，只重试打开。
- 重试中发现其他匹配群，仍需明确选择另建；最终检查失败也不会被当作没有匹配群。
- 复用主题、共享弹窗焦点管理与英文翻译。小尺寸桌面窗口固定底部操作按钮，内容区滚动。
