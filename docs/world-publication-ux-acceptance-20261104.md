# 世界发布状态与取消公开验收

基线：插件 `origin/dev f9a3da8aeb1a9b47b6dae13afdd1979dc520e146`；配套 Record 提交 `406252c57fe1b89449c2d44ede836ffc5c57b0f4`，[审查单 #496](https://codeup.aliyun.com/senguo/jotmo/jotmo-record/change/496)。本轮新代码尚未合并或发布。

## 行为

- 从已有消息进入“发到世界”只显示身份选择，不出现编辑器、附件增删或正文修改；暂不支持完整公开的消息明确阻止提交。
- 个人发布重新读取 owner/creator、来源和版本验证的已提交原消息，使用原 UID 公开，不新建或覆盖私人 Record。个人历史稿若本来使用相同 UID，可恢复标识；旧插件曾复制且未保留来源的历史稿不能按文字猜测回填。
- 账号隔离的批量发布状态供消息块和详情共享，显示小地球图标。状态只说明已请求公开，不把尚未确认的审核可见性作为已审核通过。
- 发给自己、私聊、群聊的本人原消息详情，以及本人/有当前团队管理资格的世界内容详情可取消公开。确认框明确原消息保留。个人沿用 World owner 校验，团队沿用现有权限、版本和固定请求收据。前端管理引用不授予后端权限。
- 取消失败保留原状态及重试；不确定团队结果重试相同请求。确定成功后按账号 HMAC 身份移除各入口状态，再刷新列表；其他身份发布不受影响。

## 验证范围

新增测试覆盖来源变化、私有消息不被重写、不可用媒体不静默丢弃、账号切换、签名篡改、团队不降级为个人、原请求重试、跨界面状态同步和每批最多 50 个消息。架构清单增加新 facade 方法及服务，保留原有严格检查。执行 TypeScript 声明构建、生产 bundle、可执行入口与独立 timeline worker 检查。

Record 在真实隔离 Mongo 7.0.45 副本集执行团队相关 `-race`、路由契约、架构及异常输入测试，另外运行 `internal/teamcontent` / `pkg/teamaccess` 全包测试。查询验证了来源 owner/creator/隐私锁、团队权限 epoch、跨团队隔离、分页和投影；详见后端仓说明。

真实账号使用独立本地官方 DSH 0.2.1-rc.2 Profile 与生产只读服务，实际点击了：发给自己消息菜单、身份选择与个人/团队切换、原消息详情、我的世界内容详情、取消确认与返回。没有执行生产公开或取消操作。初始和最终构建分别记录客户端 bundle SHA-256；最终构建 `b207512dda662fb7b80115a0fac94d04de2ff2cc36dbd64244058274b9a1d63e`。本地版本号沿用基线 3.0.49，并不表示已发布的 3.0.49 包含本轮修改。

测试摘要、截图及本地 Runtime 读取结果保存在工作区 `artifacts/world-publication-20261104` 与 `artifacts/world-release-20261104/world-publication-preview-3180`。原始截图含真实账号信息，不作为公共 PR 附件。
