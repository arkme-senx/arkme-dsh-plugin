# W01–W05：第一份 MR 的边界

本阶段只接通后端能力，以及既有界面的数据调用。相对官方 dev，不新增页面、按钮、标签页、菜单项、身份选择器、侧栏层级或样式。所有新增 UI 留待用户验收本阶段后另开第二份 MR；这不是 W01–W05 的完整 UI 交付。

## 能力面

| 能力 | Host / Tools / SDK | 第一阶段既有 UI |
| --- | --- | --- |
| 世界独立表态、内容版本 | 共享世界表态 owner；prepare/query/set/actors/groups | 使用原表态选择器，移除本机未同步文案；不迁移本地态度 |
| 作者归档、个人历史、自撤回、表态通知 | 只读归档及限定本人撤回均可用 | 不增加归档区或表态记录入口 |
| 当前会员等级 | 继续公开资料合同与既有批量缓存 | 原会员标识、位置、提示均保持 |
| 团队发布、来源、图片、管理、操作记录 | 同一 Team World owner 覆盖查询和幂等命令；Tools 写入继续要求显式授权 | 原发布编辑器与原身份选择器接真实发布；普通有效成员可发，不能静默切个人 |
| 混合总流、团队流、分页、回复、通知 | 团队主体和个人主体分离；新分页与线程能力由 SDK/Tools 暴露 | 总流、详情、评论沿用原控件；现有评论输入仍以个人发送 |
| 媒体撤权与账号隔离 | 新公开图片读取、原件读取、账号绑定引用 | 保留撤权失效、延迟响应丢弃、缓存清理；不引入新图片展示组件 |

## UI 明确不包含的内容

- 团队内容管理、共同反馈、原稿详情、团队操作历史及其导航。
- 原快记世界表态归档区、世界表态记录页及工具栏入口。
- 新的团队署名装饰、回复身份选择器、评论图片排版、紧凑反馈卡片。
- 独立的管理样式表、标题/头像尺寸调整、页面加宽和额外确认结果按钮。

团队的世界在基线中只有资料、发布引导和占位区域。本阶段保留结构，只将占位文案改成页面尚未提供，不伪造空列表，也不继续声称后端尚未接通。公开内容仍能通过世界总流及 Tools/SDK 读取。

## 保留的非展示语义

- 世界与私聊、群聊及发给自己作用域隔离；团队与个人身份不可替代。
- 服务端授权及当前内容版本、请求幂等、未知结果复用同一请求；原按钮用于重试。
- 评论默认展开回复，有限批次加载；沿用原“加载更多评论”和总流滚动入口。
- 通知沿用原列表交互，改读 owner 账本，最多 100 个 50 条分页；不扫描全部帖子的评论树，超限明确失败，不展示静默截断的“完整”列表。更改通知分页交互留待第二份 MR。
- 账号切换取消请求；公开图片与内部原件图片仍走不同权限 owner。
- 不改后端服务、集合、索引、配置或插件版本号。

## 验证边界

相关契约及失败路径、完整仓库测试、类型检查、构建、独立制品安装、仓外 SDK Consumer 和正式服客户端只读验收分别记录在任务交付材料。测试数据写入只允许隔离 fixture；正式服验收不发测试帖子、评论或表态。
