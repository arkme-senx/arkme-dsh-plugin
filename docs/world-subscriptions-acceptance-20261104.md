# 世界订阅与通知

个人账号可单向订阅个人或团队，无需回订。个人卡片、个人世界、团队卡片和团队世界使用统一按钮；世界保留四个导航，增加订阅管理。订阅我的可选择本人或管理的团队。团队联系固定使用该团队，沿用通道关闭提示和已有会话入口，不自动发送消息。

通知模块增加订阅筛选，展示新内容及新增订阅。关系和已读水位由 World 持久化；只展示当前仍公开的预览，失效内容无打开按钮。游标和已读凭据绑定账号；轮询30秒，列表及通知最多常驻300条。名单初始状态直接使用服务器列表，避免逐行请求。
