# 研发管家决策卡

本地 Runner 负责生命周期中的群职责配置、待决策任务、负责人校验和任务恢复。插件只消费 Bot 消息中的 version=1 jotmo-task 展示合同，不把文字中的姓名当作权限事实。

| 能力面 | 范围 |
| --- | --- |
| UI | 原群显示问题、负责人、建议、等待/已回复状态；点击从本群 Bot 清单按账号作用域的稳定标识匹配原管家，自动准备结构化 @、原消息引用和回复草稿，由用户确认发送。已有草稿或重新编辑时不覆盖。已加载的负责人回复使旧等待卡停止显示操作按钮。 |
| Host owner | 复用既有 message extension、source.send、身份及幂等流程；没有新增 Host 接口或存储。 |
| Tools / SDK | 无新增业务能力；原有聊天发送能力不变。 |

仅 Chat 标记为 Bot 的正常消息可呈现卡片。普通人粘贴协议、无效 JSON、未知版本以及转发/附件卡不会被解释为决策卡。旧客户端可阅读协议前的完整文本说明。按钮不直接批准任何任务；Runner 只接受同群当前负责人对具体问题的回复，并保留原始消息证据。普通成员即使能看见卡片，也不能藉此取得决策权限。Bot 被移出、身份无法匹配或名单尚未就绪时，不按姓名猜测、不创建无目标回复，保留原草稿并提示重试。

UI 使用 DSH 现有主题 token，支持浅色/深色、键盘原生按钮和小窗口。真实活跃状态以 Runner 和后续群回执为准，不把历史消息卡伪装成实时状态查询。
