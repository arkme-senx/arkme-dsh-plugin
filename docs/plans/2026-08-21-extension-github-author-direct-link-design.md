# GitHub 作者直达交互

## 目标

市集详情页中的 GitHub 作者身份不再打开 Arkme 作者资料卡。用户点击 GitHub 头像或名称时，直接在新标签页打开对应 GitHub 作者主页。

## 交互与边界

- GitHub 来源优先使用服务端投影的 `source_author.profile_url`。
- 缺少作者主页时，从已校验的 GitHub 仓库地址解析 owner 主页。
- 两种地址都不可用时，仅展示静态 GitHub 身份，不产生无效跳转。
- 普通 Arkme 作者继续使用现有资料卡和私聊入口。
- 页面式详情和弹窗式详情共用同一个作者触发组件，避免行为漂移。

## 能力归属

本次仅改变客户端导航行为，不新增或修改 Host API、SDK、Tools、权限、持久化或服务端契约。

## 验证

- GitHub 作者渲染为安全的新标签页链接，不再渲染资料卡按钮。
- 仓库 URL 能正确回退为 GitHub owner 主页。
- Arkme 作者仍渲染为可展开资料卡的按钮。
