### 头像缺失的证据与修复

- 复现：四段输入数据产生四段正文，但段落头像数为0；回归用例预期4个头像，修改前失败。
- 原因：头像只放在整条转发记录外层，分段循环只渲染名字、时间和正文。
- 修复：普通转发与转写分段共用独立头像行，每段都显示30px头像、说话人、时间和正文。分段与录音作者行左侧对齐，不再多缩进一层；同一说话人连续出现也保留头像。纯转写没有摘要／附件时，不生成空的作者内容行。
- 数据边界：现有分段投影只有说话人标签，没有可确认身份的头像引用，因此每段使用默认头像；不按名字猜身份，也不把录音作者头像错误复制给其他说话人。本轮没有扩大 Host 查询或权限。
