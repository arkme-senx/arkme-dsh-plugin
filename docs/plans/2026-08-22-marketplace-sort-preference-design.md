# 市集排序偏好设计

## 目标

市集首次进入默认选择“评分最高”。用户主动切换排序后，当前客户端记住该用户最后一次选择，并在该用户下次进入市集时自动恢复。

## 范围

- 仅调整 Arkme 插件市集的客户端排序状态。
- 复用现有市集排序参数和请求取消机制，不修改 Host API、Tools、SDK 或后端契约。
- 偏好按 Arkme 用户 ID 隔离；未取得用户 ID 时使用匿名作用域，不让不同已登录账号共享选择。
- 不提供跨设备同步；浏览器存储不可用时仍允许当次切换。

## 状态与数据流

1. 市集初始化时读取当前用户的排序偏好。
2. 没有记录、记录非法或存储不可用时使用 `rating`。
3. 用户选择新排序后，先更新 React 状态，再尽力写入 `localStorage`。
4. 现有发现页 effect 观察排序变化，取消旧请求并用新排序重新加载。
5. 当前用户 ID 变化时，重新读取新用户自己的偏好。

## 低保真

```text
+------------------------------------------------+
| 搜索扩展…  [分类：全部] [排序：评分最高  v]   |
+------------------------------------------------+
| loading / error / empty / success 插件列表     |
+------------------------------------------------+

用户选择“评论最多” -> 保存当前用户偏好 -> 重载列表
再次进入市集       -> 恢复“评论最多”   -> 重载列表
```

## 失败与回滚

- `localStorage` 读取或写入异常均静默降级，不阻断市集。
- 非法旧值回退到“评分最高”，不会传给接口。
- 回滚客户端偏好模块及市集接入即可恢复原行为，不涉及数据迁移。
