# 对话顶栏统一搜索与 DSH 消息搜索设计

## 目标

- 将独立“搜索”导航入口收回到对话目录顶栏的搜索框。
- 顶栏搜索框只负责打开全局搜索弹层，不再在原位置直接过滤会话目录。
- 保留现有快记搜索、搜索历史、图片库和 AI 视频入口，并接入真实语音搜索与播放。
- 在同一结果面板中增加 DeepSeek Harness（DSH）任务消息命中，并可跳回对应任务。
- Arkme 搜索结果点击后直接回到所属会话并定位具体消息，不再打开中间详情弹窗。
- 视觉结构参考 Demo 的“遮罩 + 居中搜索弹层”，颜色、圆角、阴影、字号和暗色模式继续使用当前 Arkme 客户端 token。

## 机制证据链

```text
统一搜索需求
-> Arkme SearchService 继续拥有快记/历史/图片/AI 视频数据
-> DSH 0.1.0-rc.7 SessionRuntime 公开拥有会话列表、session.search 与 open
-> 插件通过公开 ctx.sessions.search/open 注入只读客户端适配器
-> ArkmeGlobalSearchDialog 并发组合 Arkme 与 DSH 结果
-> 任一来源失败时保留另一来源，关闭弹层或切换会话即可恢复
```

DSH 兼容基准为 `dsh-v0.1.0-rc.7`（commit `99f6f02fecdb7dff40c3fbc9470f5907c29f74ca`）。该版本公开的 `ISessions.search()` 明确定义为搜索 Host 可见的消息正文索引；Host 进一步限定为当前 surface 上的 `user/message` 与 `assistant/message`，按每个任务最强消息命中返回最多 20 个 `{ sessionId, snippet }` 结果。`SessionListState.byId` 提供显示标题和更新时间，`ISessions.open()` 负责选择会话。本实现不读取 DSH 私有文件、不解析 `DSH_HOME`、也不直接读取会话 JSONL。

## 交互

1. 对话目录顶部保留当前搜索框位置和“新建”按钮。
2. 搜索框改为只读触发器，点击或聚焦后按 Enter/Space 打开“全局搜索”弹层。
3. 弹层打开后自动聚焦输入；Escape、关闭按钮或点击遮罩关闭。桌面端面板目标占比为 78% 视口宽、80% 视口高，并分别限制在 1320×780px；遮罩使用客户端底色 22% 混合和 3px 轻模糊，避免压暗底层内容。
4. 空查询按照 Demo 层级先显示搜索历史、再显示“图片 / AI 视频 / 语音”快速查找；历史使用浅底胶囊，快速查找使用描边图标胶囊，不再沿用整行列表和箭头。
5. 输入关键字后并发查询 Arkme 内容与 DSH 消息，300ms 防抖；较晚返回的旧请求通过 AbortSignal 和请求序号丢弃。
6. 结果页沿用客户端业务分类“快记 / 主题 / 录音·转写 / DSH”，各分类使用与内容类型匹配的列表或双栏结构；分来源展示错误，部分失败不遮挡已成功结果。
7. 语音结果采用“播放按钮 + 时长 + 深色转写正文 + 浅色来源信息”的客户端层级；播放地址由对应内容 owner 签发当前账号可用的短期 `mediaRef`。普通快记优先由 Record 媒体 owner 批量解析，聊天语音首次播放时通过既有 `source.timeline` 定位并复用 Chat 媒体 owner 的引用；浏览器始终只通过插件同源媒体代理分段读取，不暴露远端签名 URL。
8. 点击 Arkme 快记、主题详情或语音转写区域时关闭搜索弹层，选择其所属会话，按需向前分页加载历史，滚动到精确 `recordUid` 并短暂高亮；不再打开中间详情弹窗。
9. 点击 DSH 结果时关闭搜索弹层、切换到 Harness，并由 DSH `open()` 打开对应任务。公开 `ISessions.search()` 只提供任务级 `sessionId/snippet`，因此当前不能定位到 DSH 任务内的某条具体消息。
10. 弹层关闭按钮位于搜索框外；输入框仅在有内容时显示独立清空按钮。搜索结果的标题与摘要归一化后相同则只展示一次。

## 能力矩阵

| 能力面 | 结论 | 完成证据 |
| --- | --- | --- |
| Tools | 不新增 Tool 或 Host operation。既有记录搜索结果随安全搜索投影获得不透明 `targetSource`，模型侧查询语义不变；DSH 会话搜索仍只用于客户端导航，不向模型暴露本地任务历史。 | Tool 注册和 Schema 无改动；既有搜索测试无回归。 |
| SDK | `ArkmeSearchRecordItem` 增量增加可选 `targetSource`，语音资产增量增加可选 `mediaRef`；两者都只含浏览器安全的不透明引用，不暴露签名密钥、远端 URL 或凭据。 | 类型检查、SDK/Service 测试和真实 Host API 返回验证。 |
| UI | 顶栏入口、弹层、历史/快捷胶囊、四类结果、语音播放、部分失败、键盘关闭，以及“关闭搜索 → 选择会话 → 分页定位 → 高亮消息”的跳转状态。 | 组件测试、UI controller 测试、生产 slot 注入测试和真实页面 Host。 |
| Host owner | Arkme 内容与目标会话解析继续由现有 `SearchService` 和 `SourceService` 拥有；DSH 消息继续由 DSH `SessionRuntime` 拥有。弹层只组合展示，不复制索引、不持久化 DSH 内容。 | 复用 `search.records/search.scene/sources.list` 与 `ctx.sessions.search/open`；无新数据库、私有文件读取或凭据字段。 |

## 失败与回滚

- Arkme 搜索失败：显示“Arkme 内容暂不可用”，DSH 任务结果仍可用。
- DSH 搜索能力缺失或失败：显示“DSH 任务暂不可用”，Arkme 结果仍可用。
- 快速连续输入：取消上一 DSH 请求并忽略旧 Arkme 返回。
- 关闭弹层：取消在途请求并清空临时错误；搜索历史仍由现有 Arkme owner 保存。
- Arkme 目标消息不在首屏：每页加载 100 条旧记录，最多向前查找 80 页；找到后居中高亮，穷尽后停留在所属会话并显示无法定位提示。
- 目标会话解析失败：搜索仍可展示，点击不会伪造错误跳转；Host 解析采用尽力而为且不会让主搜索失败。
- 回滚只需恢复导航项和原搜索页入口；不涉及数据迁移、配置或 DSH 状态修改。

## 验证证据

- TypeScript 类型检查通过。
- 统一搜索及相关媒体/Host 回归在最新上游基线下共 10 个测试文件、211 个用例通过，覆盖混合结果、DSH 失败降级、旧请求取消、语音场景、按需媒体解析与播放、结果直达、导航状态、入口移除、公共 DSH 适配器和 Host 媒体路由。
- 最新上游全仓在允许临时本地端口后共 1613 个用例，1607 个通过、5 个跳过；唯一失败是基线既有的旧产品身份清理检查，与本次结果直达和语音接入无关，且本次改动未新增身份残留文件。
- 正式构建和 `.tgz` 打包通过；包内不含源码、测试、临时路径或凭据。
- 使用隔离配置的真实 DSH Web Host 和最新 tgz 启动成功。
- 真实 Host API 用“我的调休他还没通过啊”命中 `颜格蕾` 会话，并返回精确 `recordUid` 与浏览器安全的 `targetSource`；证明搜索结果具备会话和消息定位数据。
- 真实 `search.scene(scene: 'audio')` 返回当前账号语音记录，抽样结果含音频资产、时长、转写和目标会话；真实 Chat `source.timeline` 为同一记录返回不透明音频 `mediaRef`，首次播放按需解析，播放代理支持 Range，语音播放与点击跳转由服务和组件测试覆盖。
- 真实抽样“好的好的。”时长 3 秒；媒体代理对 `bytes=0-31` 返回 `206 Partial Content`、`Content-Type: audio/mp4`、32 字节响应和正确 `Content-Range`。
