# 短语音展示统一

## 已确认的展示合同

以客户端截图的 `▶ 0:02 转写文字` 为准。语音控件不添加独立底板、圆角、边框、固定宽度或进度条；外层沿用所在页面容器。图标 16px，图标与时长间距 5px，正文和时长 15px，控件与正文间距 12px。长文字自然换行，聊天可展开，详情完整展示。

覆盖聊天/个人快记时间线、群成员快记、快记详情、搜索语音入口、普通搜索及主题内语音结果。单个语音与转写同行；混合媒体/普通音频附件仍保留附件顺序，不把任意正文当作所有音频的转写。通话、长录音和声纹是不同业务，不改变其分段/试听能力；转发摘要不伪造尚未提供的媒体引用。

## 行为约束

- 有效音频时长优先；未知显示 `--:--`，通过音频元数据回填；停止时 `m:ss`，播放中显示已播时间。
- 点击/键盘播放不打开详情；正文和搜索导航保留。
- 短语音同时只播放一条，旧的异步加载不能抢回播放；卸载、换源取消未完成加载并停止旧音频。
- 加载失败保持文字可读并允许重试；不把自动播放被拒绝误报为附件损坏。
- 保留富表情、提及、长文本展开及详情原文/润色切换。

## 真实语音验收后的修复

- 普通语音是 `templateKind=3`，媒体语音是 `4`。聊天、快记详情和普通搜索都覆盖两者，不再只用类型 4 的夹具。
- 真实失败文件可以成功下载并读取时长；浏览器原生播放报 `MEDIA_ERR_DECODE`，具体是 timestamp=0、size=2 的首包。Web Audio 解码同样失败。
- MP4 解包证实：第一包与轨道的 AAC AudioSpecificConfig 完全相同，并非音频帧。去掉这个误写配置包并无损重新封装后，同一真实语音在同一浏览器完整播放到 ended（1.857596 秒），无需系统转码。
- 共享播放器仅在用户点击且原生解码失败（code 3）时启用兼容。只修复单轨 AAC-LC、首包位于 0 且与两字节配置完全相同的严格特征，不盲目删除任意首帧，不修改原文件或下载内容。
- 兼容读取仅访问同源既有媒体路由，沿用不透明 mediaRef；16 MiB、10 分钟/30,000 包、15 秒超时保护。切换、取消、卸载会中断旧请求，临时 Blob URL 在换源/卸载/失败时释放。
- 固定依赖 `mediabunny@1.55.2` 负责解封装/封装，编译进浏览器包；不引入原生解码器、全局 FFmpeg、Mac 专用命令或 DSH 修改。许可证与精确源代码获取方式见 `docs/third-party-notices.md`。

## 加载提示闪烁修复

- 根因：每次点击或进入 AAC 兼容加载，播放器插入一行 `正在加载语音…`；开始播放后删除，导致气泡变高再缩回。
- 取消这行文字。等待超过 200ms 才把原位 16px 播放图标替换成同尺寸加载图标，快速/缓存播放不闪加载图标。时长、正文及外层气泡布局保持不变。
- 保留 `aria-busy` 与按钮加载标签、再次点击取消，以及真正失败后的重试/下载提示。减少动态效果偏好下不旋转加载图标。
- 仍是同一共享组件，聊天、搜索、详情同时生效。仅 UI 展示变化，Tools/SDK 维持 N/A，Host 与 AAC 播放逻辑不变。
- 回归先红后绿：新增测试在旧实现发现额外 status 行，修复后 75 项相关测试通过；完整回归 1655 项通过、5 项跳过（236 文件通过、4 文件跳过），类型检查和构建通过。
- 浏览器慢加载夹具：加载前、加载中、播完后气泡高度均为 43.5546875px，按钮宽度均为 52.8671875px，额外 status 行始终为 0；语音正常播放到 ended。
- 无闪烁修复包 SHA-256：`c2500e30e716c749b3ded429185ef3999b35c4e3a65386000090af33be80e73e`。通过官方 DSH CLI 更新任务专用测试 Profile，安装 client.js 与构建哈希一致。旧包留存可回退，未修改常驻实例。
