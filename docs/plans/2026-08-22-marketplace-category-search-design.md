# 市集分类搜索设计

## 目标

分类数量持续增长时，用户可以在市集分类下拉中按名称快速定位分类，不必滚动浏览完整列表。

## 范围

- 仅扩展现有客户端菜单组件，并只为分类菜单启用搜索。
- 复用已经加载的分类树，在浏览器内过滤；不增加 Host API、Tools、SDK 或后端请求。
- 排序菜单保持原有结构和交互。

## 交互

1. 用户打开分类菜单后，搜索框固定在菜单顶部并自动聚焦。
2. 输入内容经过首尾空白清理和大小写归一后，对分类展示名称做包含匹配。
3. 匹配结果在下方独立滚动；无匹配时显示“未找到相关分类”。
4. 清空输入立即恢复全部分类。
5. 选择分类、点击菜单外部、再次点击触发器或按 Escape 后，关闭菜单并清空搜索词。
6. 分类加载、失败和不可用提示沿用现有状态，不发起额外请求。

## 低保真

```text
+----------------------+
| 搜索扩展分类……       |
+----------------------+
| 全部 · 307         ✓ |
| 开发工具 · 44        |
| 效率工具 · 16        |
| AI 工具 · 8          |
| ...                  |
+----------------------+

无匹配：
+----------------------+
| 不存在的分类         |
+----------------------+
| 未找到相关分类       |
+----------------------+
```

## 风险与回滚

- 分类过滤只影响菜单可见选项，不修改当前已选分类或服务端查询参数。
- 浏览器不支持搜索输入时仍可通过清空或重新打开菜单恢复完整列表。
- 回滚菜单的可搜索属性、过滤函数与样式即可恢复原行为，无数据迁移。
