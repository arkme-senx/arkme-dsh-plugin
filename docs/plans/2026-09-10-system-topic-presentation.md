# 系统主题用户侧名称

仅收口主题展示，不修改归档机制、首页开关提交语义、数据身份或数据库标题。

- topic-policy 根据 topicKind=3 提供“发给 DSH 的消息”，不依赖旧名称、record creationSource 或 UID。
- Host 目录和时间线投影提供相同的用户侧名称；sourceRef 的签名身份保持原样。
- 导航缓存保留已经取得的 topicKind，恢复时应用同一名称规则；未知类型不猜测。普通同名主题和内部 Agent 主题保持原名。
- 底部保留系统标记、归档说明和首页开关，不增加主题创建信息或耗时。不创建新配置、缓存版本或状态机。
