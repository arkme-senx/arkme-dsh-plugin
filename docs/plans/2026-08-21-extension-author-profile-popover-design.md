# 市集作者个人资料悬浮卡设计

## 目标

市集详情中的普通 Arkme 作者身份继续支持发起私聊，但视觉与宿主移动端用户资料卡保持同一信息层级。删除错误的“Arkme 作者”占位描述，并提供进入作者个人主页（“进入 TA 的世界”）的明确入口。

## 范围

- 仅调整普通 Arkme 作者的详情悬浮卡；GitHub 作者继续直接跳转 GitHub。
- 复用现有 `extensions.private-chat.open` 私聊能力，不新增 Host API。
- 复用宿主客户端既有的个人主页 action 深链，不新增页面或路由。
- 当前扩展作者投影没有个人简介字段，因此不显示伪造简介；未来只有在安全投影提供真实简介后才渲染。

## 交互与状态

1. 点击普通作者头像或名称，原位打开悬浮卡。
2. 卡片显示大头像、昵称，以及个人主页入口。
3. 点击“进入 TA 的世界”或右上角箭头，交给宿主深链打开个人主页。
4. 点击“发送消息”复用现有私聊流程；提交期间按钮禁用并显示“正在打开…”。
5. 私聊失败时错误显示在卡片内部；再次打开卡片会清除旧错误。
6. 当前用户本人不显示“发送消息”，但仍可进入自己的个人主页。

## 低保真

```text
+----------------------------------+
| [头像]  作者昵称              ↗  |
|                                  |
|                 进入 TA 的世界 > |
| [            发送消息          ] |
+----------------------------------+
```

## 回滚

改动仅在 `ArkmeExtensionAuthorPopover` 内聚合，回滚该组件即可恢复原作者卡，不影响扩展详情、安装、评论或 GitHub 跳转。
