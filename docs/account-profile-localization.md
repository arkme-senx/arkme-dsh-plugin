# 账号入口、资料编辑、关于页与语言适配

## 已确认交互

- 个人卡片昵称右侧显示小箭头；头像、昵称和 Arkme ID 属于同一个按钮，关闭卡片后直接进入「设置 → 我的账户」。右侧「我的世界」是独立按钮，只进入自己的内容。
- 我的账户使用 Flutter 移动端的独立头像行、昵称行。头像先选图、裁剪、确认，再上传并保存；昵称在对话框中明确保存。取消不提交修改。Arkme ID 仍不可修改。
- 账户余额及充值由「用量与额度」承载，不在我的账户重复显示。
- 关于页包含产品图标、版本、更新、协议、邀请得会员、社交平台和移动端相同的备案、许可证、软著及公司信息。
- 关于页精简：产品图标下不再重复显示产品名、版本号及「更新」标题；具体客户端、插件、Harness 版本行和更新入口保留。社交区复用 Flutter 的五个平台原图标，配小字名称，支持明暗主题和窄窗口换行。

## 资料写入与接口边界

- 新增插件操作 `user.profile.update`，只接受昵称或 `file_asset://` 头像引用，验证当前账号作用域与本地请求来源。
- 保存前读取 `/api/v1/auth/get-user-info` 的完整原始资料，只替换目标字段，再调用 `/api/v1/auth/update-user-info`；不使用界面脱敏的手机号、邮箱覆盖真实值。
- 保存后刷新资料缓存，并通知第一栏头像及个人卡片刷新。切换账号、卸载页面会取消在途前端请求；后端操作在读取和提交前后复核账号。
- 微信、Apple、Google 的绑定昵称有返回时直接显示，华为按绑定标识展示。当前资料接口未提供各平台头像，不用 Arkme 头像冒充微信或 Apple 头像；缺失昵称时仅显示绑定状态。
- 邀请弹窗只读取现有邀请码统计；打开关于页不会自动查询邀请码，也不自动兑换、发送邀请或创建订单。

## 中英文适配口径

- 复用 Harness 设置中的唯一语言偏好，应用菜单、设置、对话操作、搜索、录音、联系人等界面文案跟随切换，不重挂载整个应用。
- 日期和时间格式随界面语言切换；真实用户昵称、聊天内容、转写正文和法定备案名称保持原文。
- 使用移动端已有的英文文案及插件补充词典。未接入词典的服务端错误原文、历史生成摘要等仍可能出现中文，不能视为已实现任意内容自动翻译。
- 切换语言不丢失已打开的昵称编辑框和输入值；账号范围、消息类型等业务契约仍保留原值，不按显示语言改写。
