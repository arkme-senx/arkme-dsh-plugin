# 团队对话顶部工具与分析：后端交接

2026-10-20。本轮仅改 Arkme 插件前端，未修改或部署后端。

## 已有能力与前端落地

团队消息右上角现在使用普通私聊同款入口与控件：日历、搜索、对话分析、通话、更多。数据权限仍以团队接口为准，不能把团队 conversationRef 当作普通 chat sourceRef 使用。

- 日历、搜索、活跃时间和导出复用 `team.app.timeline` → `conversations/timeline/page`，通过 before_seq 顺序读取历史，每页更新进度，可暂停和重试。仅在打开工具或导出时加载，不在进入对话时扫描全部历史。
- 查询结果点击后重新核验原消息，定位到相邻消息窗口；后台更新保持历史阅读位置，有“回到最新消息”。
- 活跃时间以消息 createdAt 的本机时区统计，每个 message key 计一次。文字、图片、语音、视频、文件均计入，不以有无文本筛选。删除或不可访问消息不计入；无有效时间不进入分布并明确披露。用户选择全部成员、某个成员、某月份，查看 24 小时柱状图或周时段热力图；点击时段定位消息。
- 人物按 viewer-scoped personKey 区分，自己归为 self。昵称仅用于展示且优先备注名；相同昵称不能合并人物。缺失身份的消息仍计入消息量，不能伪造参与人数。
- 更多支持 Markdown 导出、发起个人私聊、置顶/取消置顶。导出不包含附件原件、签名媒体链接或封装的身份凭据；导出过程读取失败不能产出冒充完整的文件。
- 通话菜单明确为“以个人身份语音/视频通话”。用户选定后调用 `team.app.visitor.private.open`，服务端重新校验访客身份并返回个人私聊 sourceRef，再走现有通话流程。不是团队身份呼叫。外部侧面对团队时不猜测接听成员。

## 需要后端配合

### 1. 团队词频统计（当前未接通）

当前插件 `chat.words.*` 与 `chat.activity.*` 的服务入口只接受 private_chat/group_chat，不能用于团队消息。请给团队授权域提供独立能力查询和等价协议，或统一统计服务显式支持 team_conversation。

建议请求范围：团队/会话身份（由 Host 解封，不接受客户端任意跨团队 ID）、时间范围、时区、sender=all/self/指定稳定成员 ID。响应必须回显实际范围和用户权限域，提供统计快照版本、覆盖截至序号、完整/生成中/过期状态、进度、结果。

词频结果：word、count（出现次数）、message_count（命中消息数）、可分页关键词列表和稳定游标。关键词原文查询返回受权限保护的消息身份、seq、发送时间、发言者与文本摘要，支持精确定位。不要把 message_count 冒充 count；不支持时不返回假 0。

验收：全部发言者与指定成员、重名不同人、多媒体中可用文字、编辑、撤回/删除、离开团队、切换账号、跨月与时区边界；词云和详情原文对应同一快照。

### 2. 大会话日期索引、搜索和活跃时间聚合

现有接口只能逐页扫描，前端实现可用于当前规模，但不应让每个端永久扫描大团队全部历史。

建议新增：
- 日期索引：date、可访问消息数、当天首条稳定消息身份/seq、时区、覆盖范围；
- 搜索：关键词、sender、日期范围、分页游标、稳定消息身份、seq、命中片段；
- 活跃分布：24/168 桶、总消息数、有效参与人数、活跃天数、覆盖范围、生成状态；原文分页使用同一 result_id；
- 定位：以消息身份返回左右邻近消息，精确区分已删除、无权限、暂不可用；
- 大规模导出：异步任务、取消、进度、权限复核与短时下载授权。

需要 snapshot/revision 或一致性水位。目前 before_seq 提供序号边界，不是历史编辑/删除的原子快照，不能声称导出/统计在并发编辑时强一致。前端现阶段显示当前读取结果，新消息提示刷新；对既有历史的并发编辑需要后端版本支持。

### 3. 团队身份通话（本轮没有假装实现）

如果要以团队身份呼叫，需要单独定义外显身份、接听成员选择/分配、通话记录归属团队、录音/摘要权限、对外提示和审计。当前接入个人通话不依赖此升级。

## 数据与权限边界

每个操作必须验证当前账号、团队成员资格和具体会话访问权限。统计结果、原文分页、媒体和导出都要同样验证。不能从昵称推断用户身份，不能把团队消息交给普通 Chat 接口绕过授权。前端仅持有当前会话内存快照，切换账号/对话取消请求；无权限时清除历史结果。

## 联调方式

1. 提供 capability 响应样例和团队词频协议；插件按真实支持状态启用词云。
2. 用一段含本人、同事、外部用户和多种附件的真实团队对话核对消息总量、分时桶与源消息。
3. 大历史验证服务端分页不重复、不漏项，任务途中撤销权限后不再返回正文。
4. 保留目前的前端逐页读取作为兼容路径，服务端索引接入后优先使用索引，不重复全量扫描。

本文件不包含个人历史消息正文、账号凭据或生产导出数据。
