# 我的世界：分享建议

`WorldSuggestionsService` 是 UI、SDK 与 Tools 的唯一 Host owner。入口仅在当前账号的「我的世界」出现，不在他人或团队世界暴露私人建议。进入页面只读状态；用户点击开始分析后，才提交手动分析任务。

- UI：右侧私密建议面板，范围 7/30/90/365 天、统一模型选择、进度/取消、推荐理由及原文、暂不分享、既有身份选择发布。
- SDK：公开 `worldSuggestions` 与 `WorldSuggestionsRequest/Response` 类型；旧 Provider 没有 `worldSuggestionsV1` 时明确拒绝。
- Tools：`arkme_world_suggestions_read` 只读；`arkme_world_suggestions_change` 需要后续可信用户消息授权，不发布内容。
- 引用：任务与候选引用经过本机加密、绑定账号；原文定位留在 Host。准备与实际发布分别重新核对源权限和版本。

分析最多读取 500 条符合条件的快记，扫描上限 5000 条，结果最多 50 条。关闭面板或切换账号会取消读取；面板至多一个轮询 owner，每次响应完成后等待 4 秒，隐藏页面暂停，失败有限退避，自动轮询最长 20 分钟。进入我的世界的轻量计数不传输原文。

创建请求在传输前保存稳定 requestId 和参数，丢失回执时只核对原请求。明确未受理才能清理请求并调整参数。模型调用不会自动发布；公开内容仍由 World 审核，私密推荐理由不作为审核通过证明。

发布复用 `WorldPublishOrigin.kind=suggestion`，经候选 owner 重新获取真实 Record，再走现有个人或团队发布 owner。原文不复制、不截取替代，不回退到自由文本编辑器。成功回执后尝试私密移除该建议，清理失败不重放公开发布。

服务端顺序：先部署 Record 的取材与重验接口，再完整部署 Intelligent（包括统一模型的手动业务授权），明确配置 World 内网地址后启用，前端可以先交付未接通提示；服务端就绪后再完成全链路验收。生产尚未部署新接口时显示「分享建议服务尚未就绪」，不调用退役的 Flutter 生成接口。
