# 说话人人物入口收敛实现计划

依据：用户已确认 speaker-ui-simplified.html 四场景原型。
范围：只收敛交互，保留上一轮修改、保存接口、撤销与失败事实；不发布远端。

- [x] PeopleIdentities 移除独立 materialize 按钮，保留关联时按需建档及相关服务接口。
- [x] RecentSpeakerGroupJobs 默认收起为“最近操作”，首次展开再读取，保留任务详情弹窗、分页和撤销。
- [x] RecordingLearningStatus 默认单行状态，详情按需展开；删除手动任务重试调用，读取失败允许重新读取，核验后台重试范围。
- [x] RecordingSourceNotice 仅显示明确 stale；VersionPicker 增加版本详情弹窗，unknown 在详情说明，切换版本不串状态。
- [x] 回归测试覆盖收起/展开、失败状态只读恢复、current/stale/unknown；类型检查、bundle、510 客户端实测（边界见下）。

重点：不将学习失败冒充成功；未知来源不冒充最新；不绕过关联影响预览；关闭任务详情保留列表。

## 验证记录

10 个相关测试文件共 98 项通过；日期本地化调整后版本详情测试再次通过。类型检查、bundle 和 diff 空白检查通过。

510 客户端与插件 dev：总结与时间轴分别打开版本详情，显示对应生成时间和来源状态；底栏保留历史版本及待更新提示。最近操作默认收起，展开读取真实历史任务，打开详情后返回保留列表。人物页保留查看录音与关联身份，不再提供反向录音标记和独立建档按钮。

实测限制：人物关联面板本轮观察到能力读取中，仅核验入口及布局，未重新执行关联保存；声音参考失败状态及重新读取、unknown/current 历史来源分支通过自动测试，未以 510 制造真实故障或新生成版本。此前保存/撤销功能未改，本轮未重复数据写入。

后台核验：speaker_evidence_mutation.go 的调度仅选择 queued/processing；处理超时有重试上限，达到上限变为 failed。最终失败不会自动无限重试。本轮删除前端手动重试入口，保留真实失败状态及后台 API，没有新增恢复承诺或修改后端。

本轮未提交、推送或部署。截图位于本会话 ui-simplified-result 目录。
