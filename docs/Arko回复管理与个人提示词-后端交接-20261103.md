# Arko 回复管理与个人提示词：后端交接

日期：2026-11-03。接收：华焱（群内 mention 名 Lucis）。本版按用户最新确认的范围更新，替代此前包含风格模板、通用偏好和场景覆盖的方案。

## 本轮最终范围

只做已有提示词的查看、用户编辑和恢复默认。暂不做风格选项、模板库、通用偏好继承、模板导入或其他用户模板共享。相关模板字段不需要为本轮新建。

入口为 Arko 对话右上角“…”→“回复管理”。“回复设置”首页仅展示现有两个自动回应开关和“提示词”入口；进入后选择回复类型，直接编辑现有提示词，底部提供“恢复默认 / 保存修改”。“全部回复”继续仅汇总快记、私聊和群聊相关回应，Arko 对话直接在原对话查看。

## 桌面已经实现的部分

- 编辑区预填已有提示词的官方源码参考，直接编辑正文，不再填写另一层表达偏好。
- 以当前源码参考作为本地默认基准。恢复默认先还原编辑区；保存后去除该场景的本机修改副本。
- 按账号、回复类型保存完整提示词草稿及基准版本；多窗口冲突、存储失败不报成功；离开未保存编辑前提示。
- 本地草稿使用独立存储，不把此前的风格或补充要求当作官方提示词。之前的试验数据未被覆盖。
- 页面明确提示“仅保存在本机，尚未在云端生效”。当前保存不会启动模型，也不会修改官方或线上配置。
- Arko 对话尚无可核验的基础指令读取合同，未虚构可编辑默认内容；未接通生成的场景暂不放入提示词列表。

## 请后端优先确认或提供的合同

先核实线上是否已有下列能力；已有则提供现有接口及语义，避免重复建设。

### 读取当前提示词

按当前账号和回复类型返回：官方默认正文、当前用户自定义副本（若有）、当前有效正文、官方版本、用户配置版本，以及是否允许编辑。需要的是实际生成链路使用的配置，不只是一份静态文案。

场景 5 的收／发方向由服务端根据当前用户和原消息事实判断。Arko 对话能提供基础指令时再纳入，不填充猜测内容。

### 保存用户修改

按账号和场景保存用户级副本，沿用当前生成链路。支持配置版本比较更新，冲突时返回现有版本，不能静默覆盖其他设备的修改。返回保存是否成功、何时生效、配置版本。

本轮不需要模板 ID、风格选择、通用继承或跨用户导入合同。用户修改仅作用于后续生成，不改写历史结果，不因保存而启动一次模型调用。

### 恢复官方默认

移除当前账号、当前场景的自定义副本，返回当下的官方默认正文与版本。恢复默认不能删除历史回复，不能修改其他用户或官方全局配置。官方默认升级时，须明确用户副本继续基于哪个版本，不能静默覆盖用户文本。

### 生成链路的实际应用与边界

由后端统一组装并执行用户修改，返回实际使用的官方版本和用户版本供追溯。历史回复不能用当前配置冒充当时的配置。

源码参考正文中包含动态上下文占位符和结构化输出要求。云端合同应明确哪些段落可以编辑，哪些属于固定系统约束。消息访问权限、公开／私密范围、事实边界、工具权限和输出 schema 继续由系统控制，不能因用户保存提示词而被放宽。若接口只允许修改内容段落，请返回可编辑分块和只读说明，前端按该合同展示。

现有 AI 来信 `content-prompt-config/get|save|reset` 仅用于来信的 `tone/style/writing`。可以参考其存储、分块和版本设计，不应把快记或聊天的修改写入来信配置。

## 其他仍待对接事项

- 自动回应当前复用 `record_thought / chat_thought`，后者同时控制私聊和群聊。此次界面不再呈现虚构的独立开关，保留现有计费确认、账号校验和配置版本更新语义。
- 完整云端回复汇总仍需按账号、类型、游标读取，并由原消息 owner 校验当前权限、成员和正文版本；不得因打开列表重新生成。桌面当前汇总本次会话已读并再次校验的结果，不声称全量历史。
- 快记旧结果接口缺少记录版本／生命周期、同 UID 的 biz 1/2 去重等问题，沿用已发《阿森桌面迁移-后端交接-20261103.md》，不另建一套修复。
- 新群聊私密补充 scene 3 在本地源码仅定义，`resolveTargets` 未派发。请核验线上是否有其他生产者；它不阻塞本轮已有提示词编辑。

## 联调验收

1. 打开一种回复类型，看到实际官方默认和自己的有效修改；其他账号、其他类型不串。
2. 修改并保存后，新生成的回复使用新配置；重启和另一设备可读到相同版本。保存本身不产生模型费用。
3. 恢复默认后，新生成回到当前官方默认；原有历史回复和其他类型配置保留。
4. 两设备同时保存有明确版本冲突，不丢掉用户正在编辑的文本。
5. 修改不会破坏结构化建议输出，也不会扩大数据可见范围；生成结果可追溯实际配置版本。
6. 未提供实际提示词或尚未允许编辑的场景明确返回能力状态，前端不伪造原文或成功生效状态。
