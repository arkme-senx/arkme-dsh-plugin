# 日历日期悬浮提示即时显示

## 原因与范围

日期格原先通过原生 HTML `title` 显示「私聊 × 条 · 群聊互动 × 条」。等待时间由浏览器控制，不是统计请求导致。用户确认后，替换为即时自定义提示；没有修改日历尺寸、条数口径、数据加载或日期点击定位逻辑。

## 交互

- 鼠标移入立即显示，移出立即关闭，没有延迟定时器；相邻日期切换不残留旧提示。
- 键盘聚焦可显示，失焦、Escape、滚动、窗口缩放或失焦时关闭。
- 提示挂载在当前页面的浮层中，避免日历滚动容器裁切；根据窗口边缘调整位置，不拦截鼠标点击。
- 使用现有浅色/深色主题，并关联日期按钮的无障碍描述。空白、未知、不可用日期不制造统计内容。
- 移除原生 `title`，避免再次出现一份延迟提示。
