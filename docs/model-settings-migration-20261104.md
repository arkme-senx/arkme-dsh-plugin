# 统一模型设置入口

用户确认交互方案后，在 `codex/ts1104-11-AI额度消费统计` 继续实现。当前测试环境固定为 `http://127.0.0.1:3177/`，官方 Harness 0.2.1-rc.2，独立 DSH_HOME、profile、插件状态及测试 Keychain；原桌面环境和其他工作区未改动。

## 当前行为

- 即我设置新增一级「模型」，位于「我的账户」和「用量与额度」之间，默认「即我官方」。官方目录沿用已有搜索、场景筛选、能力和按场景计费说明，实际选用仍在各功能中完成。
- 「自提供模型」复用原生 ModelsSection、提供商卡片、ModelsSettingsStore、配置表单及凭据操作。保留编辑、添加第三方提供商、自定义模型 API 等原生能力。
- 两个标签支持方向键、Home/End；自提供页按需加载，在两个标签之间切换不会销毁配置文档或丢失未保存草稿。离开模型分类、关闭设置、退出或切换账号会卸载文档。
- AI 额度的「可用模型」导航至统一设置页，默认官方目录。Harness 设置保留单个「模型 ↗」迁移入口，点击关闭旧弹窗并打开「即我设置 → 模型 → 自提供模型」。
- 配置保存位置仍是当前 Host/profile；连接同一服务的客户端共用。没有新增账号云同步、移动端设置页面或跨服务凭据迁移，也不读取已保存密钥值。

## 复用方式与宿主路由复核

使用已有、需要 Harness 会话认证的同源 `/arkme-self/harness-frame` 页面，新增固定查询模式 `arkme-model-settings=1`。模型专页的启动图保留官方模型设置插件，移除原生设置外壳，由插件声明公开 `settings.section` 槽并只渲染 `models`。没有复制原生组件代码、读取私有 store、另建配置文件或代写密钥。

普通嵌入会话改为加载迁移入口，配置编辑插件只在专页加载，从而不产生两个相同的原生导航项；原有模型选择目录与选择器继续由其原服务管理。模型专页不安装 Arkme 会话恢复、会话观察、轨迹或引导桥。

专页的原生内容通过 Portal 呈现，并暂时使其背后的会话根节点 inert，防止输入框抢焦点。普通 Esc 经带账号作用域的同源事件关闭外层设置；原生确认弹窗及帮助浮层优先处理自己的 Esc。打开/关闭迁移事件只接受当前登录账号的作用域，旧账号事件被忽略。

宿主路由维持 GET/HEAD、已有同源认证与 Cookie 转发、no-store/nosniff；查询参数不构成外部请求地址。缺少原生模型插件或渲染适配器时显式返回 503。启动图不修改原对象，结构化批次、依赖闭包及版本修订一起投影。每个设置页最多按需加载一个配置文档，官方读取保留取消和迟到响应隔离。

本次未修改 Intelligent AI 业务代码、数据库、结算规则或凭据保存协议；因此没有新增数据库迁移或数据库回归需求。此前额度统计后端的严格 MySQL/race 验收记录继续保留在后端仓库，夹具提交 `63575dd2`、生产逻辑提交 `0491aaff`。
