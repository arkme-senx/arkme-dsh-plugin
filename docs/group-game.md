# 内部群游戏

群聊快记输入 `/game` 并发送，选择跳棋。房主复制房间钥匙，将完整文本分享给其他人；完整分享文案可正常发送为快记；接收者提取「」内的 /game join 命令，单独粘贴到群聊输入框发送以加入。只有裸命令被客户端消费。最多26个房间成员，房主选择2/3/4/6名玩家，其余观察。

独立游戏资源：`lib/game.js`，由 tsdown 构建并通过 `${routePath}/game/index.html` 与 `/game/game.js` 提供。游戏 SDK 不使用通话 iframe，退出不注销设备。设备注册仍由单一 DeviceRegistrationService 管理，新安装游戏自身的ready也能建立绑定。

桌面需要配套客户端 `zp-codex/v232-group-game` 的专用弹窗策略。旧客户端未放行时不能打开，输入保留。游戏窗口左棋盘右聊天；同设备只允许一个窗口。

后端默认启用游戏，复用 `trtc.admin-user-id`，腾讯后台必须支持Public群REST管理；管理员凭证不下发。

验证：`vitest run tests/game.test.ts tests/game-runtime.test.ts tests/device-registration-service.test.ts`；`tsc --noEmit`；`tsdown`。

浏览器隔离冒烟：`node scripts/game-browser-smoke.mjs`，需可用 playwright 和 Chrome。可用 `GAME_PLAYWRIGHT_MODULE` 指定模块路径、`GAME_CHROME_PATH` 指定浏览器。测试替换Tencent SDK和后端，只验证真实界面/游戏模块，不访问真实账号。截图输出 `test-results/game/window.png`。

真实腾讯多人联调需在部署测试后端、配置管理员后完成，模拟测试不代表已经验证腾讯生产套餐/权限。

身份配置已确认：当前worktree保留通话接收器自动登录路径，用户已确认腾讯同账号允许至少两个Web实例。游戏继续复用registration_id，并独立管理自己的SDK。未修改接收器或腾讯全局登录设置；测试服仍需验证真实多人及同时通信。

### 连接提示与回合时长（2026-11-17）

- 运行时错误优先于普通通知；复制钥匙成功提示在 3 秒后消失。
- 大厅由房主选择每回合 30／60／90／120 秒，默认 60 秒；修改后清空其他玩家准备状态，房主自动准备；开局后锁定，下一局可重新选择。时长随权威快照传递，旧快照缺少字段时按 60 秒处理。
- 已准入成员可点击“立即重连”：检查原成员准入、刷新当前身份凭证、重新登录 IM、恢复房主快照或向房主请求快照。不重新 create/join，不改变入房顺序；普通玩家收到权威快照前仍暂停。
- 房间关闭或准入失效后停止连接恢复，显示具体原因与“返回游戏选择”。回到选择页时重建本地运行时，清除旧房间关联。
- 本次修复提示遮挡和结束状态误报，并新增重连入口；不代表此前生产房间关闭原因已经查明。

- 房主在大厅自动准备，不显示准备/取消准备按钮；成员变动、人数或时长变动及进入下一局后仍自动准备，其他玩家需重新确认。

### 跳棋断线恢复修复（2026-11-17）

- 准入租约过期不再直接触发棋局退赛。房主保留缺席玩家的棋子、营地和回合顺序，继续按原有每回合计时；连续三次超时才退赛并移除棋子。
- 普通成员重连发现准入已失效时，使用内存中的原房间钥匙和新的幂等请求 ID 重新申请加入；同一次重新准入重试复用请求 ID。邀请码仍须有效，容量、设备绑定和后端准入检查不绕过。
- 房主仅根据服务端返回的 user_id + client_id 对应关系，将未退赛玩家的旧 membership_id 映射为新 ID，保留棋子位置、营地和超时次数。跨设备不恢复席位；已退赛成员重返后仅观战，下一局再分配。
- 主动退出会在释放准入前发送本人退赛动作；消息丢失时由三次回合超时收敛。房主断线且房间已关闭仍不能恢复，不迁移房主。
- 游戏 ready 阶段设备登记失败使用可识别的插件错误，显示“设备 IM 登记尚未完成，请重试”，不暴露内部异常内容。

### 多人五子棋（2026-11-17）

- `/game` 选择页提供跳棋和多人五子棋。五子棋创建参数为 `game_type=multiplayer_gomoku`，后端继续只负责准入和群管理；房间内不能切换游戏类型。
- 15×15 交叉点棋盘，2～6 人轮流、默认 2 人；每人独立颜色和编号，按入房顺序行动。任意方向至少五子连珠立即获胜，不设禁手；满盘或剩余玩家少于两人时无胜者结束。
- 点击空位预览，确认后落子，支持提交前改选/取消。房主自动准备，回合时长及准备规则复用大厅。退赛棋子保留为障碍，超时三次退赛。
- 权威状态使用 `gameType` 分派。`board` 保留跳棋结构，`gomoku` 承载五子棋；五子棋快照 `cells` 为 225 字符的 0～6 编号串，解码后恢复数组，满盘包必须低于 4 KiB。未知或跨游戏类型状态拒绝；无 `gameType` 的旧快照只按跳棋解析。
- 有效租约内重连保留五子棋身份和棋盘。五子棋准入过期后按退赛处理，重新准入仅观战；不沿用跳棋特有的过期席位接管。房主内存丢失或房间关闭后不恢复。
- 所有五子棋参与者需要升级插件；无需后端数据库迁移或桌面原生窗口修改。
- 验证：`tests/gomoku.test.ts`、`tests/game-multiplayer.test.ts`、`scripts/gomoku-browser-smoke.mjs`。真实腾讯测试入口：`GAME_LIVE_TYPE=multiplayer_gomoku` 配合既有 `scripts/game-live.mjs`；必须显式传入授权测试账号，仅连接测试环境。
