# Arko 评论连续对话

用户已确认的行为：明确回复 Arko 后，在原消息详情中异步续答；携带原始消息、被回复的 Arko 内容及当前分支历史。普通评论不触发，AI 不触发自己，公开与私密范围保持。

## 能力矩阵（实施前范围）

| 能力面 | 入口与共同合同 | 验收 |
| --- | --- | --- |
| UI | 原评论输入与回复目标；续答跟随被回复的用户评论展示，生成中/失败/重试 | 待实际页面及测试服账号验收 |
| Tools | 扩展已有 Arko 想法查询、回复工具，增加续答分页及安全重试；写入仍须明确人类授权 | 待官方 DSH 真实调用 |
| SDK | 公开类型化续答查询/重试，与 UI 共用账号及来源绑定的 Host owner | 待仓外 Consumer |
| Host owner | 统一解析 sourceRef/messageActionRef；Intelligent 校验当前 Record/Chat 事实、受众、幂等和计费操作 | 待跨仓合同及隔离数据库回归 |
| Client/Harness | 无新原生桥或安装合同；复用现有插件装配 | 不修改客户端/DSH 源码，开发实例单独验收 |

## 服务边界

Record/Chat 在现有已接受工作中把明确的 Arko 回复交给 Intelligent。Intelligent 持久保存唯一的续答任务并异步生成，生成与读取都重新回源当前权限。用户评论正文及关系仍由原 owner 持有。

托管模型使用现有积分网关的持久完成回执与稳定调用键；不增加绕过计费的直连模型路径。工作进程退出后从持久状态恢复，隐式重试不创建新的逻辑模型调用。

本轮只授权测试服部署与验收；生产发布另行确认。
