# 插件 Team 发送复用

范围仅 Arkme 插件，不以 Flutter 能力作验收证据，不改 DSH、版本或现有 Chat/Record 发送规则。

- FileTransfers 继续唯一拥有附件字节、上传缓存、账号目录和原子持久化。Team 待发只保存业务命令及本地文件引用，不另建文件缓存。
- Team 任务由 Host 持有；页面只提交、查询和展示。普通草稿不提交，明确点击发送后才接受任务。账号切换/卸载中断执行，重入原账号再按原身份恢复。
- 团队任务单独按会话顺序推进，不占用普通文件发送队列。网络失败退避；明确权限拒绝停止。新 Team 服务端不再把多人回复视为冲突；旧服务端返回的冲突仍不能静默改写已接受请求。
- 原 Chat 文件任务重启、失败和不确定结果规则不变。Team 的确认/取消不得伪装为 Chat source，也不调用个人 Record outbox。

能力面：沿本任务 Team 原生 App 合同，内置 UI 的 `team.app.*` 仍不进入开放平台 Tools/SDK；文件暂存继续调用已公开 SDK.stageFile，未新增开放平台业务入口。Host 只适配既有 Team App 发送及状态接口。

验收：离线选文件、接受后关页、同会话连续发送、重启恢复、失败兄弟附件复用、原请求重投、冲突确认/取消、切号与撤权、丢失接受回包、重复刷新与图片稳定。回归现有 FileTransfers、Chat/Record 及 UI 测试；真实测试服与设备验证单独报告。

2026-10-04 收口审核额外修复：真实发送 ACK 只有身份没有正文时，继续显示已确认的正文和附件；浏览器草稿清理失败不撤销 Host 接受或创建新请求；长时间离线排队后，有限预览和附件回收从完成时间起算，避免刚完成就消失。
