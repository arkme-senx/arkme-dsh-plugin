## 根因与最终行为

| 问题 | 根因 | 修复后的行为 |
| --- | --- | --- |
| 桌面粘贴拆段、代码字符被解释 | 所有粘贴均按完整 Markdown 文档插入 | 根据代码/段落/明确块结构选择插入方式；普通段落边界合并，代码保持字面文本，保留选择区替换及撤销重做 |
| 移动端转发缩进丢失 | 格式识别前 trim，再转发也清理文本并漏写格式 | 接收及再转发均保留 Markdown 原文与 text_format，覆盖缩进、字面反斜杠和行尾空格 |
| URL 被写入标签 | 文本范围遍历进入链接子节点 | 链接及自动链接从业务标签范围排除 |
| 标签转义后两端不一致 | 保存侧将源码当标签名，移动端直接正则扫描源码 | 保存时分离解码业务名与 UTF-16 源范围；移动端先解析 Markdown，再装饰普通文本节点，完整保留星号、下划线、反斜杠及实体字符 |
| 移动端 HTML 块消失 | 根级 HTML Text 节点被 Flutter Markdown 忽略 | 将 HTML 块包装为字面文本段落，保留原字符，不生成 HTML 元素或执行脚本 |
| 移动端链接点击被标签覆盖 | 业务识别忽略父节点语义 | 跳过链接、代码、图片字面量等节点，保留默认链接识别和点击回调 |
| 桌面分享链接标题丢失 | 只提取顶层字符串，漏掉粗体等子节点 | 递归提取完整可见标题，继续使用现有分享链接行为 |
| emoji 标签同步失败 | tags/set 用 rune 长度，正文用 UTF-16 | tags/set 与正文、mention 共用 RecordTextSpanLength；仍拒绝负值、空范围、真正越界和极大溢出输入 |
