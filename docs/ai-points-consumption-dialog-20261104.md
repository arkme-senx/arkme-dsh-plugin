# AI 额度消费记录弹窗与统计

实现分支：`codex/ts1104-11-AI额度消费统计`。开发基线：`origin/dev`，`efe2c3a3d071d6e1fbfd9f1e6ea3d221b2346dd2`。

## 行为

- 设置 → 用量与额度 → AI 额度 → 消费记录，打开独立原生模态弹窗。默认统计页、按天、近15天，并选中当天。
- 按周展示近8个自然周（周一开始），按月展示近12个自然月；账单沿用北京时间、请求创建时间的现有归属口径。
- 选择时间柱，下方显示该时段的类型消费；可查看图表整个时段。点击类型进入同一时段的筛选明细，展开保留模型、附加服务、赠送／充值来源；每次显示20组操作。
- 关闭、切号和切换查询取消旧请求；Esc、页签方向键、关闭后的焦点恢复可用。标题／页签／底部信息固定，内容内部滚动。

## 数据与兼容

唯一事实来源为已结算积分账单，不从 Token、模型名称或调用次数推算收费。优先使用新增 `/api/v1/managed-ai/points/consumption/statistics/query` 一次取得当前窗口的时间桶与业务分类；只在进入明细时调用 `/api/v1/managed-ai/points/consumption/range/query`，传所选时间、真实业务标识、固定结算截止与分页游标。Host／SDK 提供相同的账号作用域、取消和精确字符串积分合同。服务端在配套 `jotmo-intelligent-ai-points-1104` 工作区实现，无数据库迁移，不改变收费或赠送规则。

统计缓存最多8个窗口，只在当前弹窗内有效。每页明细必须与统计的筛选总额和结算截止一致；跨页请求标识去重，累计金额不得超额，最后一页逐笔合计必须与统计相等。迟到提交等导致变化时提示刷新，不显示部分合计。新接口5秒超时、8个独立读取槽、单页最多25,000底层调用，超大操作明确失败，整组返回不被截断。

只有统计路由明确404或旧Host明确不支持操作时，才回退既有月账单扫描；401、其他服务错误或数据校验失败不触发回退。以下是旧接口的兼容流程：

统计使用整数最小单位汇总。完整读取某月后，去重后的实际扣费之和必须等于首个账单快照的总额；游标必须严格递减。较新的消费若在游标上方结算，不替换首个总额；若较旧操作的迟到结算导致总额无法核对，则重新读取一次，再失败就明确报错，不展示部分统计。不同月份是各自经过核对的快照，不宣称跨月全局数据库事务快照。

并行读取最多2个月。单次加载最多240个新分页、25,000条新记录，单月最多160页；超限提示缩小范围。月趋势先以每月1组操作读取总额，再按选中月份补齐明细。弹窗内复用已核对账单；刷新／重新打开／账号或额度版本变化时重新读取。缓存最多24个月、50,000条记录，不持久化账单缓存。

已知业务标识归入 DSH、Arko、安排、个人档案、录音总结、录音时间轴、目标、实体、快记分析、聊天分析、线下交流、录音口令等分类；未知标识归入“其他”。历史未独立标记的用途不能靠前端补拆；某分类的零值仅表示此账单中没有该类型的已结算扣费。

## 验证

- 最终相关14个测试文件、230项通过，涵盖精确小额、跨月／跨年／闰年、星期边界、完整分页、总额漂移、重复数据、非法游标、资源上限、取消、账号隔离、弹窗和页签、真实来源明细及既有用量页回归；新增汇总金额守恒、单次汇总、延迟明细、跨页完整合计、SDK取消、404兼容和Esc嵌套层回归。
- 服务架构、设置架构、Host操作和通知覆盖层契约检查通过；TypeScript检查、完整构建和打包入口验证通过。
- 真实环境：本地官方 DSH `0.2.1-rc.2`、按内容哈希命名的不可变插件 tgz、独立 DSH_HOME／状态目录／Keychain 命名空间，复用用户授权的当前桌面登录态。新接口连隔离MySQL中的11,674条生产账单只读快照；其余允许的Intelligent查询仍连生产只读接口。安装包 `client.js`、`index.js` 的 SHA256 与工作区构建一致。快照保留真实请求标识、时间和扣费，隔离库主键重建，不能据此认证生产原始游标顺序。
- 真实点击：设置 → 用量与额度 → 消费记录，默认15根日柱；类型跳转并展开实际扣费明细；周8根、月12根；初版390px窗口无横向溢出。最终构建已复验：类型触发按钮卸载、焦点落到body后Esc仍只关闭消费弹窗、设置页保留、焦点恢复入口；使用宿主useModalLayer管理嵌套层。积分流程未发现脚本异常；刷新期间既有TRTC音量模块报AbortError，未验收通话功能。
- 原月分页流程：账号首次核对105页，约78.9秒；切周约3.1秒，切月约1.5秒。新汇总链路：首次点击后389毫秒、最终构建423毫秒的观察均已呈现15日统计和分类，一次汇总，Gin/SQL约16.5毫秒；周/月各一次汇总，类型明细首批20条、加载更多40条，实际DSH扣费与赠送来源展开正常。独立认证HTTP读取约231.7毫秒、5334字节，未登录401、夹具拦截模型写入403。此为本机真实账单快照观察，包含真实登录有效性探测，不是生产部署性能。
- 测试端口为 **3177**，此对话后续持续复用。配置、启动脚本、证据及日志在本工作区 `.codex-artifacts/ai-points-3177/`；其中私有就绪文件含本地 DSH 认证 URL，不应提交或分享。

本地新代码验收不等同于正式桌面客户端或已部署生产版本验收。本次没有更新正式客户端、合入 dev/master、推送、发布或部署服务端；未以真实账号发起 AI 消费或发送测试消息。后端详情、隔离库回归、竞态检查和原有基线失败见后端工作区 `docs/ai-points-statistics-20261104.md`；生产未作故障注入。

## 集成与回退

服务端汇总实现已在独立特性分支完成，待团队评审和正常测试/发布流程。服务端可先于插件上线；老客户端不受新增路由影响。生产仍未提供新路由时，新插件会兼容回退，大账号原有约79秒等待仍可能出现，不能宣称生产性能已修复。

回退可以在本地测试环境安装前一份插件包；原正式客户端和旧工作区未改动，无数据库迁移或生产数据回滚。
