# 团队自定义功能入口

开发基线：`origin/dev` / `258ab20d51b0fdef5b2570d80ae588725ba37793`。
配套 Team 服务分支：`codex/ts1104-19-团队自定义功能入口`，基于 `origin/develop`。

在联系人 → 团队详情的原有功能区中，所有者/管理员可通过“＋ 添加入口”填写名称和 HTTP/HTTPS 网址。
所有成员都能看到共享入口及目标域名；点击在新标签页打开，使用 `noopener noreferrer`。
管理菜单支持编辑和二次确认删除，每团队最多 20 个。名称最长 40 个 Unicode 字符。
入口保存在 Team 后端，跨成员、刷新或 Host 重启均共享，不依赖浏览器本地配置。

组件首次加载不阻塞原有团队功能。重新打开、窗口恢复焦点、网络恢复及可见时每 60 秒重新读取；
当前窗口保存成功立即更新。服务暂不可用时显示重试，不将失败当作可编辑的空列表。
账号切换会撤销旧请求并关闭编辑界面，包括同一批更新中切走再切回的情况。

Host 使用既有 account/teamRef 隔离，再向 Team 服务发送实际 JWT 请求；前端和 Host 均检查输入及响应契约。
版本冲突保留表单，用户显式加载最新列表并核对后再保存，防止覆盖其他管理员的入口。
相同失败命令重试保留 request UID；改动内容或重载后生成新命令。
不新增公共 SDK 工具或生产调试入口。
